### ⚠️ 100再生で0DLは「失敗」ではない。**期待値どおり**

| 段 | 一般的な率 | 100再生のとき |
|---|---|---|
| 再生 → プロフィール | 1〜3% | 1〜3人 |
| プロフィール → ストア | 2〜3割 | 0〜1人 |
| ストア → インストール | 2〜3割 | **0〜0.3人** |

**この数字からチャネルの良し悪しは判断できない。** 言えるのは
「リーチが実質ゼロ」ということだけ。**n=100 で方針を変えない。**

## SNSのミッション
**「鳥のかわいさと癒し」を外に広め、"本物の鳥への興味"の入口になる。**
売り込みでなく、見た人が「かわいい/落ち着く/へぇ(学び)」と感じて自然に共有したくなる形。

## 発信の芯(何を伝えるか)
1. **かわいい**: 来る瞬間、ドット絵、鳴き声。
2. **癒し**: 環境音+ときどきの鳥。作業/就寝BGM文脈と相性◎。
3. **学び(軽く)**: 「なぜこの鳥が来たか」を一言で。押しつけない豆知識。
4. **習慣**: 「今日も◯◯が来た」「会った日数◯日」= 日々のささやかな物語。

## SNSのルール(交渉不能)
- **誇大表現をしない**。「鳴き声が聴ける」は事実ベース(録音は xeno-canto、要クレジット)。
- **鳥の声は無料**という約束を発信でも守る(課金誘導を主役にしない)。
- **録音者・出典のクレジット**を尊重(素材の権利表記。商用可の範囲で運用)。
- **保全は"押しつけない"**。募金強制はしない。「興味を持つきっかけ」に留める。
- **他者・他アプリを貶さない**。癒し系の世界観を発信のトーンでも保つ。
- 🔴 **言い切ったことは検査対象になる**(2026-08-21 新設)。
  ストア掲載文に "A radio made only of birds you've met" と書いていたが、
  **アプリは会っていない鳥まで鳴らしていた**。数週間、嘘を出していた。
  → 新しい言い切りを出すときは **`06_監査.md` §3 の主張台帳に1行足す**。
  **検査が書けない主張は、書けるように言い換えるか、言わない。**
- **実装を見てから書く。** 「なぜ来たか分かる」と書きかけて、その欄が字幕の帯に
  隠れて**映らない**と気づいた例がある(2026-08-18)。

## ASO / ストア(公開中)
- 表示は**英語**(製品版は 2026-08-09 に日本語表示を落とした)。掲載文も英語。
- 確定コア語は `marketing/phase-s/企画部/aso_keywords.md`(cozy bird collector /
  relaxing bird sounds game / idle bird game ほか)。**高ボリュームより高一致**。
- 素材は `marketing/phase-1/SNS部/素材/store/`。スクショ6枚 + フィーチャーグラフィック
  + アプリアイコン512。**アイコンは Console だけで差し替えられる**(アプリ更新不要)。
- **売り物が増えている。** 目覚まし / 寝落ち / 餌台の駆け引きは、5型やフックバンクが
  作られた後に入った体験。古い資料に載っていないので、そのまま使わない。

## チャネル方針(2026-08-21 調査の結論)

詳細: `marketing/phase-1/SNS部/2026-08-21_TikTokかXか_事例調査と考察.md`

**TikTok を主戦場にする。X は獲得の主戦場にしない。**

- この製品には需要が**2つ**あり、両方 TikTok に居る:
  **cozy**(`#cozygaming` 245.7K投稿・競技系より供給が薄い)と
  **野鳥**(`#birdwatching`/`#birding`/`#birdtok` 合計10億再生超・
  RSPB は1年で約900万再生、うち約1/3が24歳以下)。
- **BirdTok は未使用の入り口。** いまの動画は cozy 側しか売っていない。
  本物の xeno-canto 録音と GloBI の食物網は **birder が反応する素材**。
- X は cold start の配布機構が無く(フォロワー0を配る仕組みがない)、
  インディーの成功事例も見つからなかった。birder が X を使うのは
  **珍鳥アラートの実用**で、cozy game の発見の場ではない。

### 課金は「量」ではなく「情報」に

- 広告がまだ no-fill で**回収の当てが無い**。リテンションも未測定。
  この状態で量を買うと「悪い人を大量に買った」で終わる。
- **伸びた1本を Spark Ads で数千円押す。** 目的は DL 数ではなく切り分け:
  リーチは伸びるが DL 0 → **掲載情報が悪い** / リーチも伸びない → **動画が悪い**。
  これは課金しないと分からない。
- Google App Campaigns は掲載情報の出来に依存するので**後回し**。

### 動画の作法(2026-08-08 診断書の確定事項)

- **8秒**。15秒は完走されない。完全視聴率とループが最重要シグナル。
- **冒頭1秒で動く**。以前の型は 3.2秒まで静止画に見え、最強のドット絵を
  誰も見ていない時間まで隠していた。
- **CTA を動画に入れない**("link in bio" は低実績アカウントの配信を絞る)。
- **バッチの中で変えるのは1つだけ**。何が効いたか分からなくなる。

### ⚠️ まだ読んでいない数字がある

**バッチ1の完全視聴率が未取得**(引継ぎ §7 の宿題)。8秒型に作り直した効果を
誰も測っていない。**これを読むまで課金しない。**
見るのは3つ: **完全視聴率 / 1秒残存 / 視聴者の国**。

## 中期のコラボ(SNSが橋渡し)
- 野鳥の会・博物館・保全団体・光学機器ブランドとのタイアップ発信。
- 「生態が学べる」信頼が武器。教育文脈での紹介を狙う。
