# コンセプト戦略 — 科学と教育のエッセンスがある、アメリカの庭(戦略部 2026-11-14)

CEO「生態系と鳥のつながりを考える科学や教育のエッセンスもあるアプリ。アメリカの庭をその観点から再現したい。鳥の声で起きる。調べまくって戦略を」。

## 結論(先に)

**Toris の庭は、アメリカで実際に起きている「庭を鳥の棲みかに変える運動」を、そのまま遊びにしたもの。**
これは後付けではなく、データを見たら最初からそうだった(§2)。コンセプトはこう言い切れる。

> **ドット絵の鳥が、本物の声で鳴く庭。**
> **植えたもので、来る鳥が決まる。本当に。**

1行目は 11/13 の軸(かわいさ・本物の声)。2行目が今回足す**科学の背骨**。
癒し(S1)・鳥好き(S2)に加えて、**教育(S5: 親子・小学6年・自由研究)** という第3の入口ができる。

## 1. 調べて分かった、科学の側の事実

### アメリカの庭 — 「在来の植物 → 毛虫 → 鳥」(Tallamy / Narango / Marra)
- 陸の鳥の **96%** は、ひなを**虫**で育てる(Tallamy)。種子や実ではない。
- 在来のオーク1本に **410匹(19種)の毛虫**、外来のブラッドフォードナシには **1匹**(Tallamy の計数)。
- シジュウカラの仲間(Carolina Chickadee)は、庭の植物の **70%以上が在来種**でないと個体群を保てない(Narango・Tallamy・Marra 2017、*Biological Conservation*)。
- 在来植物のうち **5% の属が、毛虫の 75% を支える**(要の植物 = keystone plants)。オークが筆頭。
- この研究が **Homegrown National Park**(自分の庭を国立公園の一部にする運動)と、Audubon の **Plants for Birds**(郵便番号を入れると、鳥のための在来植物が出る。約3,000種)になった。

→ **Toris の仕組みそのもの。** 植える → 虫が湧く → その虫を食べる鳥が来る。

### 日本の庭 — 同じ構図
- 日本野鳥の会の資料に「野鳥と木の実の相関図」(どの鳥がどの実を食べるか)。**ムラサキシキブ**が載っている。
- 都市の植物の多くが外来種になり、在来種を植える意義が語られている(キヤノン「鳥が教えてくれること」)。
- 餌台は**冬だけ**が望ましい(春夏に続けると自力で採る力が落ちる)。

### 鳥の声と、人の側(健康)
- **見る・聴くだけで気分が上がる**: 1,292人・スマホで気分を随時記録。鳥を見た・声を聴いた瞬間に幸福度が上がり、**うつと診断された人でも**、効果は**その場で終わらず続いた**(Hammoud ら 2022、*Scientific Reports*、King's College London)。
- **録音でも効く**: 鳥の声の録音は不安と被害妄想の傾向を下げた。交通音は上げた(Stobbe ら 2022、*Scientific Reports*、Max Planck)。
- **目覚まし**: 耳障りな音より**メロディのある音**のほうが、起きたあとのぼんやり(sleep inertia)が少ない(McFarlane ら 2020、*PLoS One*、RMIT)。鳥の声そのものの研究は無い。言えるのは「メロディのある音が良い。鳥の声はメロディがある」まで。

### 夜明けのコーラス(dawn chorus)
- 2025年、69種を調べた研究(Cornell ほか、*Phil. Trans. R. Soc. B*): 夜明けに鳴くのは「音が遠くまで届くから」ではなく、**縄張りの宣言**と**仲間への合図**。
- 暗闇では歌わず、明るくなると一気に歌う(ゼブラフィンチ、査読前)。「夜明けに**何かが始まる**」は科学的にもそう。

### 教育
- 小学6年 理科「**生物と環境**」(2〜3月): 食物連鎖、生産者・消費者、**食物網**。授業では簡易図鑑で「森の動物が何を食べているか」を調べる。
- 中学 理科「**生物どうしのつながり**」。
- Cornell Lab の Bird Academy は子ども向けに鳴き声当て(Bird Song Hero)や鳥の体の仕組みのゲームを無料で出している。**庭を育てて食物網を触る教材は無い**。

## 2. Toris は、もうその庭だった(データで確認)

| | 事実 |
|---|---|
| シャーロットの植物 15種 | **全部、北米の在来種**。ホワイトオーク・ハナミズキ・ハナズオウ・ユリノキ・テーダマツ・サービスベリー・アメリカムラサキシキブ…。Tallamy が「要」と呼ぶ**オーク**が入っている |
| 虫 17種 | 植物ごとに「何を食べるか」(`eats_plants`)を持つ。毛虫(オオカバマダラの幼虫、アメリカマイマイガの幼虫 等)がいる |
| 鳥 37種 | 「何を食べるか」(`eats_insects` / `eats_plants`)、「こわいもの」は **GloBI の実際の捕食記録** |
| 来る確率 | 食物の経路があるほど来やすい(`foodFactor`)。**植えたもので来る鳥が決まる**は、計算としてそう |
| 京都 | ムラサキシキブ・エノキ・クヌギ・サクラ…。野鳥の会の相関図と同じ植物 |
| 2つの土地 | アメリカ(シャーロット)と日本(京都)。**同じ仕組みが、違う生態系で動く** |

**言い切れること(主張台帳に足す)**:
- 「植えたもので、来る鳥が決まる」— 検査: `logic_test.dart` の到来確率の突き合わせ(食物の経路が無い種は確率0)
- 「シャーロットの植物は北米の在来種」— 検査: `data.py` の15種の学名と USDA の在来区分(要作業)
- 「こわいものは実際の捕食記録」— 既に台帳にある(GloBI)

**言い切れないこと**:
- 「鳥の声で起きると健康にいい」— 研究は録音の安心効果とメロディ音の目覚めまで。**「目覚ましが健康にいい」とは書かない**
- 「在来種を植えると現実の庭に鳥が来る」— アプリの外の話。**「現実でもそうです(Tallamy の研究)」と出典つきで添える**のは可

## 3. コンセプトの3つの柱と、誰に向けるか

| 柱 | 一言 | 誰に | 根拠 |
|---|---|---|---|
| **癒し** | ドット絵の鳥が、本物の声で鳴く | S1 ねこあつめ世代・S3 寝落ち | Hammoud 2022 / Stobbe 2022 |
| **科学** | 植えたもので、来る鳥が決まる。本当に | S2 鳥好き | Tallamy / Narango / GloBI |
| **教育** | 食物網を、庭で触る | **S5 親子・小6・自由研究**(新) | 小6 理科「生物と環境」 |

3つは別の製品ではない。**同じ庭を、3つの言い方で言っているだけ**。だから1つのアプリで済む。

## 4. コンセプトを製品に通す(機能)

11/12 の4つ(呼ぶなら植える・用心深さ・日記・季節)はそのまま。ここに**科学と教育の層**を足す。

### ① 植物に「要」の印と、在来の一言 — 1日
- 植える一覧で、オーク・サクラ・エノキ・クヌギなど**虫を多く養う木**に 🌳 の印。
  押すと一行: 「在来のオークは何百匹もの毛虫を育てます。鳥のひなはそれで育ちます(Tallamy)」
- 在来種に「在来」の札。シャーロットは全部在来なので、札は京都の外来候補が入ったときに効く(いまは入っていない)。
- **根拠を書く**: 出典を1行で(研究者名・年)。教育の入口は「へえ、本当なんだ」。

### ② つながり画面を「食物連鎖をたどる」に — 2日
- いまは線が多くて読めない。鳥を押すと、**その鳥に続く経路だけ**が光る(植物 → 虫 → 鳥)。
- 一行で言葉にする: 「エノキ → アオムシ → シジュウカラ」。
- これが小6理科の「食物連鎖の図」そのもの。**自由研究の1枚目**になる。
- 「なぜ来たか」(9/22 に削除)の代わりになる。あちらは作文、こちらは**図**。恣意性が無い(原則4)。

### ③ 日記(11/12 ③)を「観察ノート」としても使えるように — 日記の設計に含める
- 日付・気温・来た鳥・植えたもの・会った鳥。これは**観察記録の形式**。
- 月ごとの一覧(「11月に来た鳥」)。自由研究はこれを印刷すれば成り立つ。
- 追加の機能はほぼ要らない。日記の項目に「気温」と「植えたもの」を入れるだけ。

### ④ 目覚ましに、夜明けの科学を一言 — 半日
- 目覚まし画面の説明の下に、1回だけ出る一言:
  「鳥が夜明けに歌うのは、縄張りと仲間への合図です(Cornell ほか 2025)」
- 鳴り終わったあとの「今朝きてくれた鳥」に録音者(11/14 実装済み)。

### ⑤ 「出典」の画面 — 半日
- 図鑑の末尾に「このアプリの根拠」: 録音(xeno-canto)・捕食(GloBI)・食物網の考え方(Tallamy)・鳥の声と気分(Hammoud, Stobbe)。
- 教育で使うとき、先生・親が**これを見て安心する**。S2 の信頼にも効く。

### ⑥ 教育の入口(アプリの外) — 時期を合わせる
- **2〜3月**: 小6「生物と環境」の時期。X で「食物連鎖を、庭で触る」の投稿。つながり画面の画像。
- **7〜8月**: 夏休みの自由研究。「1か月、庭に来た鳥を記録する」= 日記そのもの。
- 学校に売り込みはしない(手続きが重い)。**親子**に向ける。

### やらないこと
- クイズ・テスト・点数(教育アプリ化)。原則1「受動的」に反する。学びは**眺めているうちに染みる**形だけ
- 現実の庭への誘導を押しつける(Audubon の郵便番号検索へのリンクは、出典画面に置くまで)
- 健康効果の言い切り

## 5. 言葉(3つの柱を1つの文章に)

ストアの「詳しい説明」の冒頭(11/14 の掲載文を差し替え):

> ドット絵の鳥が、本物の声で鳴く庭です。
> 植えたもので、来る鳥が決まります。本当に。
>
> 庭に植物を植えると、それを食べる虫が来て、その虫を目当てに鳥がやってきます。
> アメリカでは、鳥のために在来の木を植える人が増えています。在来のオーク1本は何百匹もの毛虫を育て、鳥のひなはそれで育つからです(Tallamy)。
> この庭は、その仕組みをそのまま遊びにしました。だれが何を食べるかは、実際の観察記録(GloBI)をもとにしています。
> 京都の庭と、アメリカ・シャーロットの庭。同じ仕組みが、違う生態系で動きます。
>
> 鳴き声はすべて、世界中の録音者が残した本物の録音です。鳥の声を聴くと気分が上がることは、研究でも示されています。
> 朝は、鳥の声で起きられます。
