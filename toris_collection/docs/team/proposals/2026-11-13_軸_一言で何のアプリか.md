# 軸 — 一言で何のアプリか(戦略部 2026-11-13)

CEO「将来の方向性は OK。ただ、まだどんなアプリか分からない、印象づいていない。
払拭するために軸にするのはどうすればいいか」。

## 結論

**軸: 「ドット絵の鳥が、本物の声で鳴く庭」**

- 一息で言える。絵が浮かぶ(枝に止まったドット絵の鳥)。
- **嘘が無い**(録音は xeno-canto、来る理由は GloBI)。
- **誰も持っていない**。『とりのおと』は絵も声も作り物。Merlin は本物だが庭が無い。
- 「ドット絵なのに声が本物」という**ずれ**が、人に話すときの一言になる。

この一文の下に、9つの機能を全部ぶら下げる。
機能を足すときも消すときも、この一文で説明できないものは入れない。

## なぜ今、印象づいていないか

### 1. 言葉が3つに割れている
| 場所 | 今の言い方 |
|---|---|
| ストアの名前 | TorisCollection(何のアプリか分からない) |
| ストアの一行目 | 自分だけの鳥、癒しのラジオ |
| LP の見出し | grow a tiny ecosystem, the birds come and sing |
| X の固定ポスト案 | 小さな生態系を育てるアプリ |

「ラジオ」「生態系」「コレクション」と、場所ごとに違う顔を見せている。どれも間違いではないが、**1つに絞っていない**。

### 2. 最初の60秒で、軸が体験できない
- 起動すると**ラジオのタブ**が開く。まだ誰にも会っていないので、鳴らない。「京都で鳥に出会うと、ここで聴けます」としか出ない。
- 鳥が来るのは数時間後。声を聴けるのは、さらに「耳を澄ます」で近くで会ってから。
- **「本物の声」を聴くまでに、早くて翌日**。軸がいちばん伝わる瞬間が、最初の60秒に無い。

ねこあつめは開いた瞬間に猫がいる(いないときもあるが、庭とグッズは見える)。ピクミンは歩き出した瞬間に苗が生える。

### 3. 「本物」の証拠が画面に無い
ラジオで鳥が鳴いても、誰の録音かはどこにも出ない。図鑑にも出ない。
「本物の録音です」と**言っているだけ**で、見えていない。本物であることが芯なら、証拠は画面に出すべき(原則4)。

### 4. 名前の問題(事実として書いておく)
日本で「トリス」と検索するとサントリーのウイスキーが出る。ブランドを変える話ではないが、
**ストアの掲載名には日本語の説明を足さないと検索に当たらない**。

## 軸を通す作業(機能を足すのではなく、今あるものをそろえる)

### A. 言葉を1つにする
| 場所 | 直す |
|---|---|
| ストアの掲載名 | **Toris Collection — ドット絵の鳥が、本物の声で鳴く庭** |
| ストアの短い説明 | 植えると虫が来て、鳥が来る。来た鳥は本物の録音で歌い、その声で朝起きられる。 |
| ストアの1枚目のスクショ | 枝に鳥が2羽いる庭 + 文字「声は、本物の録音」 |
| LP の見出し | 同じ一文(日本語・英語) |
| X の固定ポスト | 1行目を「ドット絵の鳥が、本物の声で鳴く庭を、個人で作りました」に |
| アプリの説明(Play の長文) | 「生態 → 愛着 → 毎日使う理由」の順(11/08 の説明戦略)。1行目は軸の一文 |

### B. 最初の60秒で、軸を聴かせる
1. **最初に開くタブを「庭」にする**(今はラジオ)。庭が主語。ラジオは庭の結果。
2. チュートリアルの「土地を選ぶ」の直後に、**その土地の鳥が3秒鳴く**。
   京都ならメジロ、シャーロットならショウジョウコウカンチョウ。カードに一言:
   「🎙 こんな声の鳥が来ます。録音: Richard E. Webster(xeno-canto)」
   - 嘘ではない(その土地に来る鳥の、実際の録音)。
   - ラジオの「会えた鳥だけが歌う」の約束は壊さない(これはラジオではなく**試聴**)。
   - ここで「ドット絵の鳥が本物の声で鳴く」が**体験として**入る。
3. 庭に鳥が来ているとき、**鳥のチップを押すと一声鳴く**(2秒)。
   来ている鳥の声が庭から聞こえるのは自然。「耳を澄ます」の手前で、軸に触れられる。
   ⚠️ 図鑑の登録や慣れには数えない(水増しにならない)。

### C. 「本物」の証拠を画面に出す
- ラジオで鳴いている鳥の行に、小さく **「録音: Peter Boesman · xeno-canto」**。
- 図鑑のプロフィールにも同じ1行(ライセンスの表記義務も満たす)。
- 目覚ましの「今朝きてくれた鳥」にも。
- これは S2(鳥好き)への信頼の証拠であり、S1 には「へえ、本物なんだ」の一言になる。

### D. 画面の名前を軸に寄せる
| 今 | 案 |
|---|---|
| 庭のラジオ | **庭のラジオ**(そのまま。「会えた鳥が歌う」を見出しの下に1行) |
| 図鑑 | **来た鳥の図鑑**(「来た」が主語) |
| つながり | **だれが何を食べるか**(機能名ではなく中身) |
| 鳥の声で起きる | そのまま(軸そのもの) |

### E. アイコン
今のアイコン(ドット絵の鳥)は軸と合っている。触らない。

## 軸で、11/12 の機能案を言い直すと

| 機能 | 軸での説明 |
|---|---|
| ② 呼ぶなら、これを植える | **本物の**食べ物の関係だから、呼び方がある |
| ④ 用心深さ・木の上に名前 | **本物の**鳥の性格に、うちの名前をつける |
| ③ きょうの庭日記 | 今日、**本物の**どの鳥が来たかの記録 |
| ⑤ 季節 | **本物の**鳥だから、季節で顔ぶれが変わる |

全部「本物」で説明できる。説明できない機能(楽器・合奏・架空の贈り物)は入れない、の判断基準にもなる。

## 順番

1. **A(言葉)と B-1(最初のタブ)**: 半日。コードはほぼ触らない
2. **C(録音者の表示)**: 半日。`_credits.json` に全部ある
3. **B-2, B-3(試聴)**: 1日。音を鳴らす仕組みは儀式とラジオにある
4. そのあと 11/12 の ② → ④ → ③ → ⑤

**A〜C を先にやる理由**: 機能を足しても、入口の一文と最初の60秒が今のままでは、足した機能も印象に残らない。
ねこあつめの「猫が庭に来る」のように、一文が先。

## 測り方
- ストア: 訪問 → インストールの率(掲載名と1枚目を変えた前後)
- アプリ: 初回起動の日に「耳を澄ます」まで行った割合(今は取れないので、取る仕組みは入れない。ストアの率で代える)
- X: 固定ポストの一文で「本物の録音」に触れた返信の数
