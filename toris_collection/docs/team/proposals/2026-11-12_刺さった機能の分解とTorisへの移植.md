# 刺さった機能の分解と、Toris への移植(戦略部 2026-11-12)

CEO「どのような機能が刺さったのか、どのような機能を追加するのがいいか、私のアプリにカスタマイズすると何か。考えて何度も」。
11/11 の文書は届け方に寄りすぎたので、今回は**機能**だけを扱う。

## 結論(先に)

ねこあつめとピクミンブルームが刺さったのは「かわいい」「放置」ではなく、次の**5つの仕組み**。
Toris はこのうち **3つを既に持っていて、見えていない**。残り2つが無い。

| 刺さった仕組み | ねこあつめ | ピクミン ブルーム | Toris の今 | 作るもの |
|---|---|---|---|---|
| ① **来るか分からない**(のぞく習慣) | 猫が気まぐれに来て去る | — | ✅ ある(来る・去る・会えない日) | 触らない |
| ② **呼び方が分かる**(集めるのに自分の手が効く) | このグッズにこのレア猫 | この場所でこのデコ | △ 計算はある(`suggestForBird`)が**画面に出していない** | **「呼ぶなら、これを植える」を図鑑に** |
| ③ **一日を振り返る1枚**(日記・アルバム・見せる) | スクショ保存・アルバム | 毎晩の「振り返り」・ポストカード | ✗ おかえり画面は消える。残らない・見せられない | **「きょうの庭日記」1日1枚 + アルバム + 共有** |
| ④ **自分のものになる**(名前・性格・妄想) | 名前・せいかく・並びで妄想 | 仲良し度 → デコ | ✅ 名前・慣れ(2.0.7)。性格は**実データがあるのに出していない** | **用心深さを出す・木の上に名前** |
| ⑤ **季節で顔ぶれが変わる**(終わらない) | 新しい猫を足し続ける | 季節イベント・歩いた場所が残る | △ 気温で来る鳥は**既に**変わる。でも誰にも見えない | **「今の季節に来る鳥」「来る季節になりました」** |

**順番**: ② → ④ → ③ → ⑤。②と④は1日ずつ、③は3〜4日、⑤は2日(データ入力を含む)。

## 1. ねこあつめは何で刺さったか(仕組みの単位で)

出典: 開発者インタビュー(週刊アスキー・Wedge)、レビュー(アプリゲット・ゲーマーズガレージ)、Quartz、Strange Horizons、White Rose の idling 研究。

| 仕組み | 何が起きるか | 人の側で動くもの |
|---|---|---|
| 来るか分からない | 庭を覗くと居たり居なかったり。急にいなくなる | のぞく習慣。「いた!」の小さな喜び |
| **グッズ ↔ レア猫** | このグッズを置くとこのレア猫、と決まっている | **自分の手で呼んだ**という手応え。集める動機 |
| **たからもの** | 猫がたまに置いていく(にぼし・どんぐり・羽) | 不意の贈り物。戻ってくる理由。人に話す種 |
| 名前・せいかく・戦闘力 | 自分で名前を付ける。性格がある | 愛着。「うちのまんぞくさん」 |
| 並びで妄想 | 猫の並びに関係を見出す | 物語を自分で作る。話したくなる |
| **写真を保存・アルバム** | 画面を写真に残せる | **Twitter に出す**。開発者が「拡散に効いた」と明言 |
| 終わりが無い・急かさない | ゴハンが切れてもゲームオーバー無し | 罪悪感なく続けられる |
| 新しい猫を足し続ける | 定期的に新猫・新グッズ | 「尽きる」を先送り |

**注意**: 「ゲーム性が薄い」と離れる人もいる(ナムウィキ)。それでも 1,500万。**薄さは欠点ではなく、入口の広さ**。

## 2. ピクミン ブルームは何で刺さったか

| 仕組み | 何が起きるか | 人の側で動くもの |
|---|---|---|
| **歩いた道に花が咲く** | 現実の行動が地図に残る | 自分の生活が作品になる |
| **毎晩の振り返り** | その日の歩数・花・写真を1枚に | 1日を締める儀式。写真を撮る理由 |
| デコピクミン(場所ごと) | レストランで拾った苗はコック帽 | 現実の場所と結びつく収集 |
| ポストカード | おつかいに出したピクミンが実在の場所の絵葉書を持ち帰る | 不意の贈り物(ねこあつめの たからもの と同じ役) |
| 大きな花・キノコ | みんなで歩くと咲く。協力して倒す | コミュニティ(台湾で半年14.3倍) |
| 仲良し度 → 姿が変わる | 育てた分だけ見た目に出る | 愛着の可視化 |

## 3. Toris の今(持っているもの・見えていないもの)

| | 状態 | 備考 |
|---|---|---|
| 来るか分からない | ✅ | 3時間に1コマ。会えない日もある |
| 呼び方 | **計算だけある** | `toris_core.suggestForBird` は Python と1480通り突き合わせ済み。**アプリから一度も呼ばれていない** |
| 振り返り | ✗ | おかえり画面は閉じると消える。アルバムも共有も無い |
| 名前 | ✅(2.0.7) | 1種3羽まで |
| 性格 | **データだけある** | `wariness`(用心深さ)が全種にある。到来の計算には使っているが、図鑑に出ていない |
| 季節 | **計算だけある** | 月ごとの気温で来る鳥が変わる(`temp_fit`)。説明文には「冬に来る」「夏の渡り鳥」と書いてある。**画面はどこにも「今の季節」を出さない** |
| たからもの | ✗ | 落とし物は 2026-08-15 に CEO 判断で廃止 |
| コミュニティ | ✗ | 「みんなの庭」は Streamlit 版でも非表示。サーバーが無い |
| 終わりが無い・急かさない | ✅ | 原則1・2 |

## 4. Toris 向けに作り替えると、こうなる

### ② 「呼ぶなら、これを植える」(図鑑のヒント) — 1日

- **何**: 図鑑の各種に1行。まだ来ていない「???」にも出す(種名は伏せたまま)。
  - 「🌱 エノキを植えると、来やすくなります」(直接)
  - 「🌱 クヌギを植えると、クワガタムシが来て、それを目当てに来ます」(間接)
- **元**: `suggestForBird`(直接→間接の順で返す。Python と同じ)。
- **なぜ効く**: ねこあつめの「グッズ↔レア猫」。いま Toris は「なぜ来ないか」が分からない。
  分かった瞬間、植えるのが**作戦**になる。食物網(原則4)がそのまま遊びになる。
- **原則**: 嘘が無い(計算どおり)。急かさない(ヒントは静かに1行)。
- **ねこあつめとの違い**: あちらは攻略サイトが答えを教えた。Toris にはコミュニティが無いので**アプリが教える**。

### ④ 性格を出す・木の上に名前 — 1日

- **用心深さ**: 図鑑のプロフィールに「用心深さ ●●●○○」(wariness から)。
  慣れメーターの隣に置くと「用心深い鳥ほど、慣れたときが嬉しい」が読める。
- **木の上に名前**: 名前をつけた子が枝にいるとき、鳥の上に小さく「ピョンタ」。
  ねこあつめの「並びで妄想」はここから始まる。スクショにも名前が写る。
- **原則**: 用心深さは実データ(原則4)。

### ③ 「きょうの庭日記」 — 3〜4日(いちばん大きい)

- **何**: 1日1枚、自動でできるカード。
  - 日付・土地・気温・天気(嵐が来たなら🌀)
  - 来ていた鳥(ドット絵、名前のある子は名前つき)/ 近くで会えた鳥 / 旅立った子
  - 一言(今ある おかえり の要約をそのまま)
  - 名前をつけた日、初めて来た鳥の日は **印** が付く
- **どこ**: 図鑑タブの隣に「日記」。めくると過去の日が並ぶ(アルバム)。
- **共有**: カードを画像にして Android の共有シートへ(X に直接出せる)。画像の下に小さく Play のリンク。
- **なぜ効く**: ピクミンの「振り返り」+ ねこあつめの「写真・アルバム」+ とりのおとの「招待状」を1つにしたもの。
  **「見せたくなる1枚」が、ボタンを足すのではなく、製品の中から自然に生まれる**。
  11/08 に「共有画像は No」と判断されたが、これは共有機能ではなく**日記**。共有は日記の出口の1つ。
- **原則**: 自動で生まれる(原則1)。開かなかった日は空白のまま、連続日数は数えない(原則2)。事実しか載せない(原則4)。
- **技術**: Flutter の `RepaintBoundary` → PNG → `share_plus`。サーバー不要。日記は端末に保存(引っ越しコードには入れない)。

### ⑤ 季節 — 2日

- **何**: 図鑑に「留鳥 / 夏鳥 / 冬鳥」の印と、並び替え「今の季節」。
  月が変わったら一言「ジョウビタキが来る季節になりました」(1回だけ)。
- **データ**: 種ごとの渡り区分(留鳥・夏鳥・冬鳥)を `data.py` に足す(37種。実在の知識)。
  来やすさ自体は**既に**気温で変わっているので、計算は触らない。
- **なぜ効く**: ねこあつめは「新しい猫を足し続ける」ことで尽きるのを防いだ。Toris は絵も音も増やせない(ライセンス)。
  **季節は、素材を増やさずに顔ぶれが変わる**唯一の手。1年で4回、戻ってくる理由ができる。
- ⚠️ 2026-08-14 に「季節での**絞り込み**」は廃止した。今回は絞らない。**情報として見せるだけ**。

## 5. 検討したが、今回は出さないもの

| 候補 | 元 | 出さない理由 |
|---|---|---|
| **羽根(たからもの)** | ねこあつめ・ポストカード | 2026-08-15 に CEO が「落とし物は要らない」と判断。ただし、ねこあつめで人が**いちばん話題にする**のは たからもの。出すなら「名前をつけた子だけが、たまに羽根を1枚」まで絞る。**CEO 判断待ち** |
| 楽器・合奏 | とりのおと | 架空。本物の録音が Toris の芯(原則4) |
| みんなの庭・大きな花 | ピクミン | サーバーが要る。ユーザーが増えてから |
| 連続ログイン・デイリー | 一般 | 原則1・2 に反する。ねこあつめも無しで伸びた |
| ポストカード(旅立った鳥の便り) | ピクミン | 渡り先は実在(ツバメ→東南アジア)だが、絵が要る。季節(⑤)で代える |

## 6. 何を測るか

- ②: 「???」の鳥が来るまでの日数(ヒント前後で比べる)
- ③: 日記を開いた日数 / 共有された回数(共有シートに渡した回数を端末で数える)
- ⑤: 月替わりの週の、開いた人の割合
