# 図鑑エンハンス企画提案 — コレクション動機を高める(実生態ベースの"鳥となり") 2026-08-03

作成: 企画(PJ管理代筆)/ 位置づけ: 提案書。実装はCEO承認後に開発部。

## 背景・狙い
実機確認で、図鑑のリストは汎用の青い鳥絵文字、詳細も簡易情報が中心で、**「集めたくなる個性」が薄い**。
CEO指示: 各鳥に**エピソード/好きなもの/こわいもの/好きな場所**等を足してコレクション動機を上げたい。

## ⚠ 大原則(交渉不能・原則4=生態に誠実)
**これらは全て"実際の生態"から出す。作り話の可愛い豆知識にはしない。**
- **好きなもの** = 実際に食べるもの(既存 `eats_plants` / `eats_insects`)
- **こわいもの** = 実際の天敵(GloBI `preysOn`/`eatenBy` の捕食者=**肉食鳥拡張の猛禽**と直結)
- **好きな場所** = 実際の生息環境(biome + habitat 情報)
- **エピソード** = GloBI/実データから引ける生態の一言(例: モズの"はやにえ"は既に description にある。誇張・虚偽なし)

これにより「かわいい個性」と「本物の学び」を両立する(=このアプリ独自の価値)。

## 提案する図鑑詳細カードの構成(1鳥あたり)
既存の詳細(スプライト/学名/説明/See a photo/Wikipedia)に、以下の**"プロフィール"行**を足す:

| 項目 | 出典(実データ) | 例(Northern Cardinal) |
|---|---|---|
| 🍽 好きなもの | `eats_plants`+`eats_insects` の表示名 | ヒマワリの種、いくつかの虫 |
| 😨 こわいもの | GloBI `preyedUponBy`/猛禽の `preys_on` | クーパーハイタカ |
| 🏞 好きな場所 | biome + 生息環境ラベル | シャーロットの茂み・庭先 |
| ✨ ひとこと | description(実データ)/GloBI由来の生態1行 | 年中さえずる真っ赤な鳥 |
| 🪶 会った日数 / 観察回数 | 既存 bird_days / observed | (既存を流用) |

- **見せ方**: アイコン+短文の1行ずつ。静かなトーン(押し売りしない)。**"会った"鳥ほど情報が開く**
  (既存の「近くで会うと詳細が記録される」仕様=正しい仕様を活かし、集める動機に変える)。

## コレクション動機の設計(なぜ集めたくなるか)
1. **一羽ずつに"本物の物語"**: 好き/こわい/居場所が実生態で埋まる=図鑑が"生きた生態系の地図"になる。
2. **関係で繋がる**: 「この鳥のこわいもの=あの猛禽」「この鳥の好きなもの=あの虫」と**図鑑内でリンク**させ、
   集めるほど食物網が見えてくる(企画ミッション「遊ぶほど生態系がわかる」を図鑑で体現)。
3. **罰しない(原則2)**: 未収集は「まだ会っていない」だけで、減点・急かしは一切足さない。

## データ・実装の要点(WHATのみ・実装は開発部)
- **好きなもの/好きな場所**: 既存フィールドから生成(新データ不要)。表示名は既存の `disp()`/`_net_node_label` を流用。
- **こわいもの**: 肉食鳥拡張の `preys_on`(GloBI由来)を逆引き。**肉食鳥拡張と同時 or 後**に入れるのが自然
  (天敵が図鑑に無いと"こわいもの"が空になるため、猛禽提案と足並みを揃える)。
- **エピソード**: まず既存 description を活かし、余力で GloBI 由来の1行を足す(恣意的生成はしない)。
- i18n: 追加ラベル(🍽好きなもの 等)は日英両方。値は表示名ヘルパー経由(EN画面に日本語を出さない=直近の監査教訓)。

## 段階案
- **Phase G1**: 好きなもの/好きな場所/会った日数の"プロフィール行"(既存データのみ・低リスク)。
- **Phase G2**: こわいもの(肉食鳥拡張の `preys_on` 逆引き)を追加。→ 図鑑内リンクで食物網を見せる。
- **Phase G3**: エピソード拡充(GloBI由来の一言)。

## 承認が必要な事項
- `05_運用ルール` §1: 図鑑UI+データ表示の変更=CEO承認後に実装。特にG2は肉食鳥拡張とセット。
- 「こわいもの」を出すことが原則2(罰しない)と両立するか(=表示は"生態の事実"であって、
  プレイヤーへの脅威・急かしではない、という線引き)をCEO確認。
