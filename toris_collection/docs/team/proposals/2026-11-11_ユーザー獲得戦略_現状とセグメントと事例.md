# ユーザー獲得戦略 — 現状・セグメント・事例から(戦略部 2026-11-11)

CEO「とにかくユーザー数を増やしたい。現状、セグメントを的確に行い、事例を調査して課題と戦略を。
ねこあつめ、ピクミンブルームみたいなのをイメージして作った」。

## 結論(先に)

1. **いちばんの課題は「アプリの出来」ではなく「誰にも見つかっていない」こと。** 累計3インストール・レビュー0件。
   じょうごの最初の段(知る)に、まだ1人も入っていない。
2. ねこあつめが伸びた仕組みは**「人に見せたくなる1枚」が Twitter で回ったこと**。開発者自身がそう言っている。
   いまの Toris には、その1枚が無い。**これを作るのが最大の一手**(以前「No」と判断されたが、事例を見て再提案する)。
3. 狙う順番は **S1「ねこあつめ世代」で量を取り、S2「鳥好きで見に行けない人」で信頼を取る**。
   S1 は Hit-Point(ねこあつめの会社)の『とりのおと』が既に座っている席なので、**かわいさでは戦わず「本物の録音・本物の生態」で差をつける**。
4. 費用は0のまま。やることは **(a) 見せたくなる1枚 (b) ストアの入口を日本語で直す (c) X で2週間毎日出す**。
   この3つを30日やって、Play の獲得数と保持率で次を決める。

## 2. 事例から学ぶこと

### ねこあつめ(Hit-Point、2014-10 公開)
- 公開から数か月は **1日数百 DL で伸び悩み**。2015年1月末から Twitter で急伸 → 2月末に100万 → 3月に App Store 無料1位 → 8月に640万。
- 開発者の分析: **ゲーム画面を写真として保存できる機能が SNS 拡散に効いた**。猫45種の「動きに癒される」。普段ゲームをしない人が遊んだ。課金も広告もほぼ無し。開発は2人。
- **Toris への示唆**: 伸びるまで3〜4か月かかっている。伸びた瞬間は「機能」ではなく「見せたくなる1枚」。
  同じ会社が『とりのおと』(鳥版)を出している = **S1 の席は空いていない**。

### ピクミン ブルーム(Niantic/任天堂、2021-10 公開)
- DL の52%は初年度。その後の売上の伸びは **ユーザー増ではなく課金の深化**。売上の半分は日本。
- 台湾では2026年に SNS の投稿量が半年で14.3倍 = **コミュニティが自走**したとき伸びた。
- 定着の仕組みは「**歩く**」という現実の習慣に乗せたこと(休眠が少なく8割がアクティブという分析)。
- **Toris への示唆**: 現実の習慣に乗せるのが定着の鍵。Toris の「歩く」に当たるのは **朝(目覚まし)と夜(寝落ち)**。
  これは既に入っている。売上はユーザーが増えてからの話。

### 近い席にいるアプリ(日本・鳥)
| アプリ | 中身 | Toris との違い |
|---|---|---|
| **とりのおと**(Hit-Point) | 広場にごはんとグッズを置くと鳥が来て楽器を演奏 | 架空の鳥・作り物の音。**本物の録音・本物の生態は無い** |
| とりおっち2 / とりあつめ! / めーさん日記 | 餌を置いて眺める・卵を孵す・写真を撮る | 同上 |
| 野鳥GO / Merlin / 見つけた!野鳥図鑑 | **外に出て**本物を識別・記録 | 外に出る前提。**家にいる人には使う場面が無い** |

→ **「本物の鳥が、家に来る」は、どちらの側にも無い。** ここが Toris の席(8/11 の市場分析と同じ結論)。

### cozy ブーム(2026)
- Steam の cozy タグは1年で +143%。**棚が混んでいる**。「cozy」という言葉自体が検索の取っ手になっている。
- Merlin(鳴き声で識別)が 2021 に TikTok 発でバズり、20〜30代に birding が広がった(`follow_targets_strategy.md`)。

## 3. セグメント

| | 誰 | 大きさ | 刺さるもの | 見つかる場所 | 優先 |
|---|---|---|---|---|---|
| **S1 ねこあつめ世代** | 30〜40代、ゲームをしない人も含む。かわいい・癒し・集める。スクショを投稿する | **最大**(ねこあつめ 1,500万) | ドット絵の鳥、名前をつけた子、おかえりの一言 | X(日本)、アプリ紹介サイト | **◎ 量** |
| **S2 鳥好きで見に行けない** | 20〜30代中心。Merlin 以降の birding 層。都市・時間なし | 中 | **本物の録音**、和名・学名、食物網、GloBI | X の野鳥タグ、birding コミュニティ | **◎ 信頼・口コミ** |
| S3 寝落ち・作業 BGM | 幅広い | 大だが競合も多い | 焚き火+鳥、寝落ちタイマー、目覚まし | 検索(「睡眠 音」) | ○ 定着の理由 |
| S4 個人開発者 | 作る人 | 小 | 開発ログ、会計士×個人開発 | X #個人開発 | △ 拡散の燃料 |

**8/11 の文書は S2 を先に、と言っていた。今回は S1 と S2 を同時に取る**。理由: S1 だけだと『とりのおと』に負ける。S2 だけだと数が出ない。
**S2 の人が「本物だ」と言ってくれることが、S1 に広がる信用になる**(ねこあつめも最初は少数の熱心な人から広がった)。

## 4. 課題(優先順)

### 🔴 課題1: 見せたくなる1枚が無い
ねこあつめの決め手。いまの Toris で人に見せられるのはスクショだけで、文字が多く、鳥は小さい。
- **作るもの**: 「ルリツグミのピョンタが来ていました」の**共有カード**(ドット絵・和名・名前・日付・庭の絵)+ Play のリンク。
  おかえり画面と図鑑に［シェア］ボタン。Android の共有シートに渡す(X に直接出せる)。
- **なぜ今か**: 名前の機能(2.0.7)ができたので、「うちのピョンタ」という**語れる主語**ができた。名前の無い鳥のスクショは誰のものでもない。
- ⚠️ CEO は 11/08 に「No」と判断した。**事例を見たうえで、もう一度だけ提案する**。作る量は中(2〜3日)。

### 🔴 課題2: ストアで見つからない
- 名前が「TorisCollection」だけ。日本の人は「鳥 放置」「鳥 癒し」「鳥 鳴き声 ゲーム」で探す。**どれにも当たらない**。
- スクショが英語。日本語版を出したのに、ストアの絵は英語のまま。
- レビュー0件。0件のアプリは入れる前に止まる。
- **直すもの**: 掲載名を「Toris Collection — 鳥が来る庭と、本物の鳴き声ラジオ」のように日本語の取っ手を入れる(30字以内)。
  スクショを日本語の画面で撮り直す(1枚目は鳥が2羽いる庭、2枚目は図鑑の和名、3枚目は目覚まし)。
  説明文を「生態 → 愛着 → 毎日使う理由」の順に書き直す(11/08 の説明戦略と同じ順)。
  友人に**正直なレビュー**を1件頼む(頼むのは規約上 OK。見返りを渡すのは NG)。

### 🟡 課題3: 発信がまだ0本
X の投稿キットは8本ぶん用意できているのに、出していない。TikTok は数字を記録していないので「伸びない」が確かめられない。
- **やること**: 2.0.7 が公開されたら、固定ポストから**1日1本、2週間**。返信には全部返す。
  野鳥アカウントには宣伝せず、本当の感想だけ(原則4)。
- TikTok は「やめる」ではなく「**数字を写すまで判断しない**」。13本ぶん、再生・完全視聴率・国を `posts.csv` に写す(30秒×13)。

### 🟡 課題4: Android だけ
日本の X ユーザーは iPhone が多い。見た人の半分以上は入れられない。CEO は iOS を「No」と判断済み。
→ 固定ポストに「iPhone 版が欲しい人はひとこと」を入れて、**需要を数える**だけにする。数が出たら再検討。

### 🟢 課題5: 最初の鳥が来るまでの体験
2.0.7 で「最初の1羽は初日」を守った。2.0.6 以前を入れた人は 2.0.7 の案内を見ていない。ここは様子見。

## 5. 戦略(30日)

| 週 | やること | 担当 |
|---|---|---|
| 1 | 2.0.7 の却下理由を直して公開 / ストアの名前・説明・スクショを日本語に / 共有カード(課題1)を作る | 開発部・CEO |
| 2〜3 | X 投稿キット8本 + 共有カードの投稿。1日1本。返信は全部返す / TikTok の数字を写す | CEO・SNS部 |
| 4 | Play Console の **獲得数(X 経由)** と **保持率(1日目・7日目)** を読む。S1/S2 どちらの投稿が伸びたかで次を決める | 戦略部 |

**目標の目安**(0円・Android のみ・口コミだけ): 30日で **インストール 30〜100**。
1,000 に届くのは「1本が回った」か「紹介サイト・クリエイターに拾われた」ときだけで、狙って起こせない(ねこあつめも3か月かかった)。
**打席数を増やす**のが唯一できること。

## 6. やらないこと(理由つき)
- **かわいさだけで『とりのおと』と戦う**: 相手は ねこあつめの会社。勝てない。本物の録音と生態で差をつける
- **広告で量を買う**: AdMob 未承認で回収できない。保持率も未測定(8/21 と同じ結論)
- **機能を足し続ける**: 届いていないうちは、足しても答えが出ない
- **連続ログイン・通知攻め**: 原則1・2 に反する。ねこあつめも「まったり」で伸びた

## 7. 測るもの
- Play Console: **ユーザー獲得(ストア訪問→インストール、流入元 X)**、**保持率(1日目・7日目)**
- X: 投稿ごとのインプレッション・返信・プロフィール訪問。「iPhone 欲しい」の返信数
- アプリ内の分析ツールは入れない(方針どおり)
