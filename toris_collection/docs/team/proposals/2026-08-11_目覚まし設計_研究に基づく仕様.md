# 鳥の声の目覚まし — 研究に基づく設計（2026-08-11）

作成: PJ管理部 / 位置づけ: **実装仕様**（MVP は本書に沿って実装済み）。
CEO 指示「研究などを読み込んだうえで、効果的な機能で設計して」。

**一行**: 研究が言っているのは3つ。**(1) 耳障りな音は目覚めを悪くする、
(2) ゆっくり立ち上げると目覚めが良くなる、(3) 鳥の声は自然音の中で最も回復効果が高い。**
この3つを満たすと、設計は「フェードイン」ではなく「**夜明けのコーラスの再現**」になる。

---

## 1. 読んだ研究と、そこから決まったこと

### 研究1: 耳障りな音は睡眠慣性を悪化させる
**McFarlane, Garcia, Verhagen & Dyer (2020), PLoS One**
「Alarm tones, music and their elements: Analysis of reported waking sounds to counteract sleep inertia」

- **メロディのある音**で起きた人は、目覚めの覚醒度が高い。「ビープ音」のような
  耳障りな音は**朝のぼんやり（睡眠慣性）を強める**。
- 続く実験（**Clocks & Sleep, 2020**「Auditory Countermeasures for Sleep Inertia」）では、
  **メロディ条件だけが**注意の脱落（attentional lapses）とフライング反応を有意に減らした。
  **リズムだけの条件では有意差が出なかった。** 効くのは「メロディの輪郭」。
- 睡眠慣性は**最大4時間**パフォーマンスを下げうる。軽視できない。

> **→ 決定1: 目覚ましに使うのは「さえずり（song）」だけ。「地鳴き・警戒声（call）」は使わない。**

これは飾りではなく、**この設計で最も重要な判断**。実際に調べたところ:

| 鳥 | 録音の種別 | 目覚まし |
|---|---|:--:|
| Northern Cardinal | **song** | ✅ |
| American Robin | **song** | ✅ |
| Song Sparrow | **song** | ✅ |
| Carolina Wren | **song** | ✅ |
| **Blue Jay** | **call** | ❌ **使わない** |
| Mourning Dove / Downy Woodpecker / Barn Swallow ほか | call | ❌ |

**アオカケス（Blue Jay）の call は「ジェー！」という耳障りな叫び**で、
研究が名指しで警告している harsh な音そのもの。最初に同梱していたが**外した**。

### 研究2: ゆっくり立ち上げると目覚めが良い（dawn simulation）
**Dawn simulation** は臨床的な裏づけのある数少ない寝室技術で、
冬季うつに対して**8件の臨床試験**で改善が報告されている。

- 起床の **20〜90分前**から徐々に強度を上げることで、
  **コルチゾール覚醒反応（CAR）**を促し、睡眠慣性を下げ、気分を改善する。
- 光と音を組み合わせる装置では、自然音を **30dB → 55dB** へ徐々に上げ、
  **最大照度の約4分後**に最大音量へ到達させる設計が採られている。

> **→ 決定2: 立ち上げは「秒」ではなく「分」。最大音量まで約5分かける。**

当初の実装は **45秒**だった。これは研究の想定より一桁短く、
「ゆっくり起こす」になっていなかったため、**300秒（5分）に変更**した。

### 研究3: 鳥の声は、自然音の中で最も回復効果が高い
**Ratcliffe, Gatersleben & Sowden (2013), Journal of Environmental Psychology**
「Bird sounds and their contributions to perceived attention restoration and stress recovery」

- 自然音の中で、**鳥の声が最も「注意の回復」「ストレスからの回復」と結びつけられていた**。
- 回復効果が高いと評価された鳥の声は、**緑地・春夏・日中・活動的な情景**と
  結びついていた。
- 別研究（**Scientific Reports, 2022**）では、鳥のさえずりが**不安と被害妄想を和らげる**。

> **→ 決定3: 「朝・春夏・活気のある庭」の情景を音で作る。** 単独の声を鳴らし続けるより、
> **複数種が加わっていく**方が、研究が言う「活動的な情景」に近い。

## 2. 設計 — 「夜明けのコーラス」

研究の3点を満たすと、単純なフェードインではなく**段階的なコーラス**になる。
本物の dawn chorus も、1種が鳴き始め、少しずつ他の種が加わる。

```
時刻      層                        音量        情景
─────────────────────────────────────────────────────────
0:00      1羽目（さえずり）が疎らに   8% →       「夜明け前」
1:40      2羽目が加わる              30% →       「空が白む」
3:20      3羽目が加わる              60% →       「朝」
5:00      全部そろう                 100%        起きる
─────────────────────────────────────────────────────────
15:00     自動停止（電池を焼かない）
```

**設計上の決めごと**

| 項目 | 決定 | 根拠 |
|---|---|---|
| 使う音 | **さえずり（song）のみ** | 研究1（メロディが効く／harshは逆効果） |
| 立ち上げ | **5分かけて 8%→100%** | 研究2（dawn simulation の時間感覚） |
| 開始音量 | **聞こえるか聞こえないか** | 研究2（覚醒閾値の下から始める） |
| 層の増え方 | **1羽 → 2羽 → 3羽** | 研究3（活動的な情景ほど回復効果が高い） |
| 音源の所在 | **APK 同梱** | Render のコールドスタート22.7秒では朝に間に合わない |
| 自動停止 | **15分** | 電池と近所迷惑 |

### 寝過ごし対策（研究にはない、実務上の必須事項）
競合の **Dawn Chorus** は「1分で勝手にスヌーズして止まる」とレビューで指摘され、
**寝過ごす**という致命的な評価を受けている。優しい目覚ましの最大のリスクはここ。

- 5分で最大音量に達した後、**止めるまで鳴り続ける**（勝手に静かにならない）。
- ただし**耳障りな音への切り替えはしない**（研究1に反するため）。
  上げるのは**音量と密度**であって、音の質は変えない。

## 3. 実装（MVP・実装済み）

WebView の中では作れない（アプリを閉じていても鳴る必要がある）ため、ネイティブ側に置いた。

| ファイル | 役割 |
|---|---|
| `BirdAlarmBridge.java` | Web から時刻・鳥を受け取る（JavascriptInterface）。`setExactAndAllowWhileIdle` で登録 |
| `BirdAlarmReceiver.java` | 発火を受けてサービスを起動（Receiver 内で鳴らすと数秒で殺されるため） |
| `BirdAlarmService.java` | フォアグラウンドで、上表のスケジュールに沿って鳴らす |
| `BirdAlarmSounds.java` | さえずりのみの対応表 |
| `res/raw/alarm_*.mp3` | 同梱音源（全て商用可 CC0/BY-SA・計約1.6MB） |

- **サーバーに一切依存しない。** 圏外でも機内モードでも鳴る。
- Doze（省電力）を貫通するため `setExactAndAllowWhileIdle` を使用。
- Android 13+ は `USE_EXACT_ALARM`（目覚まし用途は追加許可不要）、
  Android 12 は `SCHEDULE_EXACT_ALARM` の許可確認と設定画面への誘導を実装。

### 既知の限界（正直に）
- OEM の「電池の最適化」が強い端末（一部の中国系メーカー等）では発火が遅れうる。
  純正 Android では Doze を貫通する。
- 全画面表示（フルスクリーンインテント）は未実装。通知＋音のみ。
- **実機での検証が未了。** 目覚ましは信頼性が全てなので、
  実機で「アプリを閉じた状態・画面ロック・機内モード」の3条件を確認するまで、
  公開版には出さない。

## 4. 承認が必要な事項
