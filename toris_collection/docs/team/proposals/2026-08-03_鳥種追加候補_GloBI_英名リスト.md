# 鳥種追加候補(GloBIベース・英名リスト) — 2026-08-03

**用途**: CEOがドット絵を作る対象を選ぶための候補リスト(英名だけでよい、との指示)。
**根拠**: `tools/globi_raptor_pull.py` と同様に GloBI 実データから抽出。各バイオームの
**既存の昆虫**(食物網に既にある種)を GloBI で `eatenBy` 検索し、**それを食べる鳥**のうち
**現ロスターに無い種**を候補とした。恣意的に足さず、本物のGloBIエッジのみ。

> ⚠️ GloBIは全世界の記録を含むため、**地理的な妥当性は要最終確認**(例: 欧州の種が
> シャーロットのエッジに混じることがある)。下記は「鳥である可能性が高く・地理的にも
> その土地に居そう」なものを優先して英名化した。最終選定はCEO/企画で。数字は
> 「その鳥が現ロスターの何種の昆虫を食べるか(=食物網の太さ)」。

## 追加時の必須確認(`designbird`拡充の前提。別紙 "鳥追加チェックリスト" と同じ)
1. **簡易スプライト** `designbird/{bird_id}.png`(64×64透過)= 必須。詳細は任意。
2. **データ1件**: 和名/**学名(上表)**/英名/color/**eats_insects**(上表の"網"に対応する既存昆虫id)/eats_plants/temp_fit/biome/rarity/wariness/説明。
3. **鳴き声=自動**(学名でxeno-canto取得)。
4. **⚠ 食物網のつながり**: 上表の候補は「既存の昆虫を食べる」ので、`eats_insects` にその昆虫idを入れれば庭に来る(飾りで終わらない)。天敵(肉食鳥拡張)との整合も追って。

## 次アクション
- CEOが上表から作る種を選定 → ドット絵制作 → 開発部がデータ登録(GloBIの eats を根拠に)。
- 地理的に微妙な種(Steller's Jay / Great Tit 等)は、企画で在来性を最終確認してから採用。
