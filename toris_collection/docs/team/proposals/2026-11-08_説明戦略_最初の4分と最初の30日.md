# 説明戦略 — 最初の4分と、最初の30日(戦略部 2026-11-08)

CEO「チュートリアルで、目覚まし機能とか、名前機能とか、生態学にもとづいて来る仕組みとか、
色々考えたうえで説明戦略をたてて」。

## 結論

1. **最初に全部は説明しない。** 機能が意味を持つ瞬間に、その1つだけを一言で出す。
2. 最初のチュートリアルで伝えるのは2つだけ。
   **「植える→虫→鳥」の生態のつながり**と、**「鳥は時間をかけて来る」**こと。
3. チュートリアルの最後で**目覚ましを1回だけ勧める**。
   毎朝アプリに触れる理由ができて、通った日数(庭のなじみ)がそのまま積み上がる。
4. 名前は図鑑の奥に置かない。**6回目に近くで会ったその場で「名前をつけますか?」と聞く**。
   これがこのアプリでいちばん嬉しい瞬間で、X に投稿したくなる話題になる。

## なぜ全部を最初に説明しないか

- アプリには、ラジオ・耳を澄ます・図鑑・つながり・目覚まし・道具・慣れ・名前・庭のなじみと、9つの仕組みがある。
  最初に並べても覚えられないし、静かな世界観(原則5)も壊れる。
  CEO が 8/20 に「説明良くわからん、文字多いし消していい」と言ったのも同じ理由。
- 一方で、**今は大事な仕組みのいくつかが見つからない**。目覚ましの許可、名前の枠、珍しい鳥の条件など。
  何もしなければ、使っても気づかれないまま終わる。
- → **使いたくなる瞬間に、その1つだけを出す**。出すのは1回だけ。
  一文の目安は日本語で30字前後。急かさない言い方にする(原則1)。

## 新しい流れ

### A. 最初の4分(チュートリアル。段は増やさず、最後の段だけ差し替える)

| 段 | 見出し | 一言 | 意図 |
|---|---|---|---|
| 0 | 土地を選ぶ | シャーロットか京都。いつでも変えられます | (今のまま) |
| 1 | 何か植える | 植物は虫を呼び、虫は鳥を呼びます | **生態の核**(今のまま) |
| 2 | 虫が来た | この虫を目当てに、鳥がやってきます | (今のまま) |
| 3 | **鳥は、ゆっくり来ます** | **数時間ごとに、だれかが立ち寄ります。明日の朝、鳥の声で起きてみませんか?** ボタン:[目覚ましをセット] [あとで] | **戻ってくる理由を渡す**。目覚ましは任意。「あとで」で何も失わない |

- 「目覚ましをセット」を押したら目覚まし画面へ移り、許可(通知・正確な時刻)もそこで案内する。
- 最初の鳥はチュートリアル中には来ない。**初日に1羽は来る**ように数字を合わせてある(2.0.7、シミュレーション済み)。

### B. 最初の30日(その瞬間に1回だけ出す一言)

| いつ | 何を出すか | 伝えたい仕組み |
|---|---|---|
| **はじめて鳥が来ていた**(おかえり画面) | 「耳を澄ますと、近くまで来てくれます」 | 耳を澄ます |
| **はじめて近くで会えた** | 「会えた鳥は、ラジオで歌います」(今もある「ラジオに新しい声」と統合) | ラジオ |
| **2回目に近くで会えた** | 「会うほど慣れてくれます。慣れ ●●○○○○」 | 慣れ |
| **6回目に近くで会えた** | **その場で「すっかり慣れてくれました。名前をつけますか?」**(入力欄つき・「あとで」可) | **名前**(最大の山場) |
| **名前をつけた子が、はじめて来た** | 「ルリツグミのピョンタが来ていました」+ **[シェア]**(画像を作って X へ。別途作る) | 名前 → 口コミ |
| **3日目に開いた**(庭のなじみ Lv1) | 「庭がなじんできました。珍しい鳥が少し来やすくなります」 | 庭のなじみ |
| **同じ顔ぶれが続いたとき**(5回開いて新しい種が来ない) | 「植えるものを変えると、来る鳥が変わります」→ つながりへ | 生態(食物網) |
| **はじめて道具が使えるようになった** | 今の「きょうの道具」の説明のまま | 道具(広告) |

- 全部「**1回だけ**」。出したかどうかは端末に記録して、二度と出さない。
- 目覚ましは A の最後で1回だけ勧める。断った人には、**はじめて近くで会えたとき**に
  「会えた鳥で、朝起きることもできます」と**もう1回だけ**添える。それ以上は勧めない。

## 外での言い方もこの順にそろえる

ストアの説明・X の固定ポスト・LP も、同じ順番で書く。

1. 植える → 虫 → 鳥(生態のつながり。ほかのアプリとの違い)
2. ゆっくり来る / 慣れる / 名前をつけられる(愛着)
3. 鳥の声で起きる・寝落ち(毎日使う理由)

## 測り方(アプリに分析ツールは入れない)

- Play Console「ユーザー獲得 → 保持率」の **1日目・7日目**を、変更前後で比べる
- 名前の機能の効き目は、**X で「ピョンタが来た」投稿が出るか**で見る(シェアボタンを付けてから)

## やらないこと

- 最初に機能を一覧で並べるツアー
- 「毎日開きましょう」「連続◯日」の言い方(原則1・2)
- 何度も出る通知やバッジ。一言は1回きり

## 実装の見積もり

- A の最後の段の差し替え + 目覚ましへの導線: 小
- B の一言たち(1回だけ出す仕組み + 文言8つ + 日英): 中
- 6回目の「名前をつけますか?」をその場で出す: 小(図鑑のダイアログを流用)
- シェア画像: 中(別の提案として出す)
