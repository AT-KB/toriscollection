## 2. 作りの要点(ここを読めば続きが書ける)

**`toris_app/lib/i18n.dart` がすべて。**

- **辞書の鍵は「画面に出ている英語そのもの」。** 辞書に無い文言は**英語のまま出る**(落ちない)。
- 既定 **EN**。選択は SharedPreferences の `app_lang` に保存。
- 切替は **図鑑タブの先頭**。設定画面が無く、図鑑は文字を読む画面なので自然に収まる
  (庭やラジオの上に出すと、静かな画面に操作子が増えて原則5「かわいさ優先」に障る)。
- 画面の建て直しは `main.dart` の `ValueListenableBuilder<Lang>`。

### ⚠️ 前提が1つ崩れていた
`main.dart` には「文言は `i18n.py` の出荷済み英語を引き写す」と書いてあったが、
**引き写されていなかった。** 画面の文字列 84 件を `i18n.py` の TRANSLATIONS
(384件・日本語→英語)と機械で突き合わせたところ、**日本語が取れたのは 9 件だけ**。
残りは Flutter 用に新しく書かれた文言で、**訳は新しく起こした。**

### ⚠️ `toris_core` は1行も触っていない
チュートリアルの文言(`toris_core/src/tutorial.dart`)も顔ぶれの一言
(`stories.dart`)も **core にある**が、どちらも**固定の文**なので
**表示側で `t()` に通せば英語がそのまま辞書の鍵になる**。
→ **Python との突き合わせにも台帳にも影響しない。**
(一度「core の作りを変える判断が要る」と CEO に報告したが、**誤りだった**。)

## 3. 🔴 監査の規則を書き換えた(今回いちばん大きい変更)

`tools/migration_audit.py` に「**画面に日本語(アプリは全部英語)**」という規則があった。
2026-08-09 の「表示は英語のみ」という方針に基づくもので、日本語切替を入れた途端に
**110 件の誤検出**になった。

**規則を消さず、約束のほうを書き換えた。**

```
旧: 画面の文字列に日本語があってはならない
新: 英語を選んでいる人に、日本語が漏れてはならない
```

日本語があってよいのは2つだけ:
1. **辞書そのもの**(`lib/i18n.dart`)
2. **言語で分岐している行**(`L10n.lang.value == Lang.ja ? ... : ...`)
   — 日本語で語順が変わる文は辞書に載せられないので分岐で持つ

三項演算子が複数行に折れるので、**4行さかのぼって**分岐の目印を探す
(`JP_GUARD_LOOKBACK`)。言語の名前(「日本語」)は英語の画面でもそのまま
(`JP_ALLOWED_TEXT`) — **言語名はその言語で書くのが世界共通のやり方**で、
英語の人が探せなくなるため。

**わざと壊して落ちることを確認済み**: 分岐の外に生の日本語を直書き → exit 1 /
辞書から鍵を消す → exit 1 / 元に戻すと exit 0。

## 4. 試験(`toris_app/test/i18n_test.dart` 7件)

**画面が使っている鍵が辞書に全部あるか**をソースを読んで突き合わせ /
訳が鍵と同じままになっていないか。

**わざと壊して落ちることを確認済み**(辞書から鍵を消す・訳を英語のまま入れる・
言語を保存しない の3通り)。

### ⚠️ この試験は誤報もする
ソースを読む方式なので、**改行の書き方(バックスラッシュ + n)を2文字のまま拾う**。
辞書の鍵は Dart が評価したあとの文字列なので、**ある鍵を「無い」と誤って言った**
(2026-10-20 に実際に起きた)。いまは試験側で戻しているが、**鵜呑みにせず中身を見ること。**

## 5. 実機でしか見つからなかったもの(2つとも試験は通っていた)

1. 🔴 **`home: const HomeShell()` の `const` で、切り替えが効かなかった。**
   const は同じインスタンスとして扱われるので、言語が変わって `MaterialApp` を
   建て直しても**その下が丸ごと飛ばされる**。Flutter の典型的な落とし穴。
   → **中身が言語で変わる widget に const は付けられない。**
   実際、`t()` を入れた 20 箇所前後で `const` を外すことになった。
2. 🔴 **図鑑のラベル欄が日本語だと値とくっついた**(「好きな場所Charlotte」)。
   幅 62 は英語の LIKES / HOME / FEARS に合わせた値だった。
   → **言語で幅を変える**(日本語は 84、字間を詰めず大文字化もしない)。

**教訓: 翻訳は「文字を置き換える」だけでは終わらない。幅・語順・const が付いてくる。**

## 6. 踏んだ罠(次の人へ)

- **辞書に書いた改行が、本物の改行として書き込まれた。** Dart の文字列が途中で
  切れて 62 件のエラーになった。スクリプトで辞書を書くときは要注意。
- **同じ英単語を別の意味で使っている箇所がぶつかる。** `'Plant'` は
  庭の見出しでは「植えたもの」、つながりの凡例では「植物」。
  **鍵が英語そのものである以上、これは起きる。** 庭側を `'Planted'` に分けた。
- **日本語で語順が変わる文は辞書に載らない。** 「はじめまして、◯◯。図鑑に加わりました」
  「◯◯ が来ていました」「N 分」「庭で近くで出会った N 羽の中から」は
  **分岐で持っている**(辞書ではない)。監査の規則もそれを前提にしている。
