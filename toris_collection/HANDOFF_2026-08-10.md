### ⚠️ 公開版に残っていた不具合を2つ発見して修正した(どちらも実機で発見)

**(1) 言語設定が全ユーザーに漏れていた**
`i18n.set_lang()` が無条件にモジュールグローバル `_fallback_lang` を書き換えていた。
Streamlit のモジュールはプロセス内で共有されるため、**誰か1人が日本語に切り替えると、
同じサーバープロセスに来た新規ユーザー全員の既定言語まで日本語になっていた**。
本番が日本語で表示されていたのはこれが原因。
→ サーバー上(ScriptRunContext がある時)は session_state だけを書き、グローバルには
触らないようにした。判定に `streamlit.runtime.exists()` を使うと pytest 中も True に
なってテストが壊れるので、**`get_script_run_ctx()` の有無で判定する必要がある**。
回帰テスト2件あり。

**(2) 開発用パネルが公開版に出ていた**
サイドバーの「🧪 開発テスト用」に、コードのコメントで
「本番リリース時にはこのブロックごと削除する想定」と書かれたまま、
**誰でも押せる時間の早送り・鳴き声ライセンス監査・GloBI プレビュー・データ全削除ボタン**が
露出していた。時間の早送りは交渉不能の原則1(受動的である)に正面から反する。
→ `SHOW_DEV_TOOLS = False` で隠した(削除はしていない)。

## 2. 判明した事実(次のセッションが同じ道を辿らないために)

### 🔴 LP の配信元はこのリポジトリではない
`torriscollection.com` は **`AT-KB/aviation-note-site`** リポジトリの GitHub Pages
(CNAME=torriscollection.com、`main:/` 配信)。
このリポジトリの `landing/` は**原稿**で、公開はそちらへ `index.html` を
コピーして push する運用。**ここを知らないと、LP を直しても本番に出ない。**
`app-ads.txt` も同じ場所に置いてある。
(このリポジトリ自身の Pages は `main:/docs` で、中身は日本語のプライバシーポリシー1枚)

### 🔴 AdMob が通らない理由は app-ads.txt ではない
ファイルは完璧に配信されている(3つのURL形式すべて 200 / text/plain / BOMなし /
リダイレクトなし / 中身も正しい)。
**原因は、Play に登録されているデベロッパーサイトが `at-kb.github.io` のままで、
AdMob がそこをクロールして 404 になっていること。**
- アプリのウェブサイト(ストアの設定 → 連絡先情報)= torriscollection.com に変更済み・反映済み
- **デベロッパー アカウントのウェブサイト(デベロッパー アカウント → アカウントの詳細)
  = ここがまだ。これが本命。**
アプリに埋まっている App ID は**この判定に一切関係ない**(確認はストアのドメインを
クロールするだけで、アプリの中身は読まない)。

### 🔴 公開した versionCode 5 にテスト用 AdMob App ID が埋まっていた
2026-07-11 に「アカウント承認が済むまで」と一時的にテストIDへ戻したものが、
そのまま製品版まで出ていた。versionCode 6 で本番IDに戻し、AAB をビルド済み。
**まだアップロードしていない。** 広告は `ADMOB_ENABLED` 未設定で完全に止まっているので、
実害(誤配信・規約違反)は起きていない。

### AdMob には関門が2つある
| 関門 | 状態 | できること |
|---|---|---|
| アプリの確認(app-ads.txt) | 失敗中 | あり。デベロッパーサイトを直せば通る |
| アカウントの確認 | 「確認中」 | **なし**。Google 側の処理待ち(最大2週間) |
両方揃うまで広告は出ない。**AdMob は製品版公開のブロッカーではなかった**
(むしろストア公開が AdMob の前提)。

### 事前登録は挟まない判断
需要を「溜める」機能であって「作る」機能ではない。流入が無い状態で箱だけ作っても
入らず、その間アプリがダウンロードできず AdMob も止まる。
→ 先に静かに公開し、その後で宣伝する。

### 生態ログの日本語は仕様上の残骸
実機に「カロライナコガラが来ました…」等が残るのは、**日本語表示だった時期に
文章として保存された過去の記録**。コードの不具合ではなく、新規ユーザーには出ない。
(engine が文章を組み立てて保存する設計のため、後から言語を変えられない)

### 環境メモ
- **Windows + OneDrive で gradlew がファイルロックで落ちる**。
  `Unable to delete directory ...mergeReleaseResources` 等。
  `./gradlew --stop` してから該当ディレクトリを削除。それでも駄目なら `app/build` ごと削除。
- **gradlew が BUILD FAILED でも `adb install` は成功しうる**(古い APK が残っているため)。
  必ずビルド結果を確認してからインストールすること。
- **実機に release APK を上書きインストールできない**(端末に入っているのは debug 署名)。
  アンインストールすると進行データが消えるので、確認は debug ビルドで行う。
- `streamlit.runtime.exists()` は pytest 中も True。ランタイム判定には
  `get_script_run_ctx()` を使う。
- 実機の画面確認はブラインドのタップではなく **CDP でタブを切り替える**のが確実。
  手順は `store_assets/screenshots/README.md`。
