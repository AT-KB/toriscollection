## 1. 移植したロジック(すべて差分テスト付き)

`toris_core/` は**UI を持たない純粋 Dart パッケージ**。`dart test` だけで速く回る。

| Dart | 元 | 中身 |
|---|---|---|
| `save_code.dart` | save_code.py | JSON → zlib(9) → base64url。旧形式も読む |
| `engine.dart` | engine.py + absence_loop.py + disturbance.py | 下記 |
| `ecology.dart` | ecology.py | ギルド・気候の重なり・食べ物の重なり・共起・顔ぶれの抽選 |
| `flock.dart` | flock.py | 群れの大きさ(観察回数で育つ) |
| `badges.dart` | badges.py | 会った日数の節目 |
| `py_coerce.dart` | — | Python の `int()`/`float()` と同じ型変換 |

### engine.dart の中身(この商品の背骨)

```
気温     = その土地の平均 + 月ごとのオフセット(南半球は半年ずらす)
気温適合 = 適温の幅の中なら 1.0 近く、外れると 0.9^超過 で急に落ちる
食物網   植物: 適合 0.05 未満は育たない
         虫  : 適合 0.1 未満、または食草が1つも無ければ湧かない
         鳥  : 流れ込む重みの合計が食物網スコア
到来確率 = 気温適合 × 土地(好む土地なら1.0、外なら0.15)
           × 食物網(1 - 0.6^スコア) × レア度((1-rarity×0.85)×0.9) × 0.5
```

最後の 0.5 は「滞在2〜4種の落ち着いた庭」に収めるための引き締め。
中心性(Sony CSL の PageRank 補正)は移していない — 現行もデータが無ければ
シードの rarity を使う作りで、そちらに合わせた。

### 1コマ(tick)と時間の進み方

**時間は勝手に進む。押して進める仕掛けは置かない**(原則1「受動的である」)。
画面を開いた時に、前回からの経過ぶんだけ庭が動く。

```
5分未満  → 0コマ(何も起きない)   6-12時間 → 4コマ
5-30分   → 1コマ                12-24時間 → 5コマ
30分-2時間 → 2コマ               24時間以上 → 6コマ(上限)
2-6時間  → 3コマ
```

**1コマの中の順序は変えないこと**(結果が変わる):
1. 撹乱を引く(10%。嵐0.55/落雷0.30/伐採0.15)。倒れる確率 = 強さ × 植物の
   倒れやすさ。**全滅しそうなら1本残す**(最後の緑は失わせない)
2. 退去判定(滞在中の各鳥。退去率 = 0.3 - 0.25 × 到来確率)
3. 到着判定(候補をシャッフルしてから。滞在は最大4種、1コマで新規は1種まで)

**確率はコマごとに計算し直される**。撹乱で植生が変わるため、
`runTurn` は毎回 `buildFoodWeb` を呼ぶ。

### 図鑑の登録は3段階(ここを間違えた)

**来訪＝近くで出会った、にしてしまい「全部登録される」状態を作った。** 正しくは:

| 状態 | 条件 | 見た目 |
|---|---|---|
| ❓ | 未来訪 | 名前も `???` |
| 🐦 | **到来イベント** → `discovered` | 名前は出るが**絵は出ない** |
| 🪶 | **儀式で近距離観察** → `observed` +1 | **ドット絵が出る** |

- **ラジオの近さ(b1/b2/b3)と群れは `observed` を見る。** 来訪しただけでは
  近くで鳴かない。会いに行くから馴染む。
- 会った日数(`bird_days`)は**鳥ごとに**1日1カウント。アプリ全体で1回にすると、
  同じ日に後から来た鳥が数えられない。
- 庭が痩せても、図鑑と日数は減らない(原則2「罰しない」)。

## 2. 音(移行の心臓部)

### 実時間の処理を、事前処理に移した
現行は再生しながら毎フレーム RMS を測り、ノイズゲートと AGC をかけていた。
**この2つは鳴らす前に済ませられる。** 移植が難しい処理ではなく、
**そもそも持ち込む必要のない処理**だった。

```
ノイズゲート → afftdn(暗騒音そのものを消す)   実測: 暗騒音 -42 → -67 dB
AGC         → loudnorm(音量を揃える)         実測: 36本すべて -19.4 LUFS 付近
```

### 音の作りで、現行と揃えたもの(一度ずらして直した)
| | 値 | どこで |
|---|---|---|
| ハイパス | **820Hz** | 素材に焼き込み(全鳥共通) |
| 存在感EQ | 3.5kHz / Q0.9 / **+5dB** | 素材に焼き込み(同上) |
| 奥行きのローパス | b1 12k / b2 8k / b3 4.6k | 実行時の biquad |
| 奥行きの音量 | b1 1.12 / b2 1.00 / b3 0.85 | 実行時 |
| 残響の深さ | b1 0.01 / b2 0.09 / b3 0.20 | freeverb |
| 定位 | 3羽を左右に均等 | 実行時 |
| 群れ | 0.09〜0.42秒ずらして重ね、左右に広げる。後ろほど小さく | 実行時 |

ハイパスと存在感EQを**素材に焼く**のは、SoLoud が音源につき biquad を
**1つしか持てない**ため(そちらは奥行きのローパスに要る)。

### 音で踏んだ罠(全部実機で発覚)
1. **freeverb はモノラルに使えない。** かけると金属音になる。素材はステレオで用意する。
2. **音声は1羽1本を使い回す。** 鳴くたびに play() すると重なって膨らむ。
   鳴く/休むは音量だけで表す。画面に「鳴っている音声の本数」を出してある
   (鳥3 + 環境音7 = 10 で張り付くのが正しい)。
3. **`MediaPlayer.create(ctx, res)` の後に setAudioAttributes は効かない。**
   目覚ましがアラーム扱いされず、OS にバックグラウンド再生としてミュートされた。
   属性を渡す方の create() を使う。**製品版にも同じ不具合があった。**
4. **loudnorm だけでは音量が揃わない。** 鳴きが疎な録音は目標に届かない。
   実測して差分を当て直す。ただし LUFS はゲート付き測定なので**1回では合わず、
   繰り返す**。
5. **alimiter は既定で音量を戻す。** `level=disabled` が必須。

### 音源の差し替え(2026-08-15 追加)
自動で選んだ1件が「その種らしさ」を外すことがある(環境音でも起きた)。
**詳細絵がある23種**(図鑑の顔になる種)を対象に、取り替える道具を用意した。

```sh
py -3 tools/bird_audio_swap.py                   # 対象と、いまの音を一覧
py -3 tools/bird_audio_swap.py american_robin    # 候補を出す
py -3 tools/bird_audio_swap.py american_robin 1138978  # 取り替える
```

取り替えた音も**同じ工程を通る**(暗騒音の除去 → 音量を揃える → ステレオ)。
飛ばすと1羽だけ浮く。`_credits.json` の出典も一緒に書き換わる
(ライセンスの追跡を切らさないため)。

### ライセンス
CEO 判断で **NC(非商用)も使う**(いまは広告を入れておらず商用ではない)。
36種中 **商用可6 / NC30**。1件ずつ `_credits.json` に記録してあるので、
広告を入れる段で差し替える対象がそのまま一覧になる。
同じ品質なら配布可を優先して選んでいる(追加コストゼロで将来の手間が減る)。
**イカル(Eophona personata)だけ声が無い** — 32件の録音が全てダウンロード不可。

## 3. Flutter 版の現在地

`toris_app/`(パッケージ名 `com.toriscollection.toris_app`。製品版
`com.toriscollection.app` とは**わざと別**。同じにすると Play 版を潰す)。

5タブ: **Radio / Garden / Guide / Network / Wake**

- **Radio**: 36種から3羽。環境音7層。**睡眠モード**(15/30/60/90分で
  画面を暗くしたまま鳴り続け、最後の1分で沈む)。画面が消えても鳴るのは
  `RadioService`(音を持たない、居るだけのフォアグラウンドサービス)のおかげ。
- **Garden**: 木の情景(3層の枝に鳥が止まる)、土地(Kyoto/Charlotte)、植える
  (下から出るシートで選ぶ)、湧いている虫、留守のあいだの出来事。
  **出会いの儀式**(耳を澄ますと鳥が枝を移り、手前で2歩留まると出会い)。
- **Guide**: 全37種の折りたたみ。並びは地域別/レア度順。上記の3段階。
- **Network**: 同心円の図。植物=濃い緑で大きく/虫=小さい肌色/来た鳥=その鳥の色/
  届く鳥=淡い/**届かない鳥=最外周に極小のグレー**(手が届いていない量も情報)。
- **Wake**: 目覚まし。止める道が3つ(通知のボタン・通知の本文・アプリ内)。

### ビルドの注意(OneDrive)
`build` と `.dart_tool` を **OneDrive の外へのジャンクション**にする。
同期がビルド中のファイルを掴んで Gradle が落ちる。加えて、残った Gradle
デーモンがファイルを握って `AccessDenied` になることがある — その時は
`Get-Process java | Stop-Process -Force` してから中間物を消す。
