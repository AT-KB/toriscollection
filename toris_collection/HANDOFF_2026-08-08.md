### B. Android: versionCode 4（スプラッシュ修正をテスターに届ける）

※ release APK は端末の既存インストール（debug 署名）と署名が合わず上書き不可。
**アンインストールすると端末の進行データが消える**ため、debug ビルドで確認した

## 2. 判明した事実（次のセッションが同じ道を辿らないために）

### 広告（AdMob）は**製品版公開のブロッカーではない**
- **`ADMOB_ENABLED` は未設定（既定 False）で、`render.yaml` にも記載が無い = 広告は現在1つも出ていない。**
- 本番 App ID は**取得済み**（`strings.xml` のコメントに記録: `ca-app-pub-9002945296291643~1195899268`）。
  2026-07-11 に「AdMobアカウント承認が済むまで本番IDでは配信されない」ためテストIDへ**一時的に**戻した経緯。
- AdMob 管理画面の現状 = **「お客様のアカウントは確認中です」**（24時間〜最大2週間・待つのみ）。
  残タスク「アプリストアにリンクする」は、**Play で一般公開されていないと実行できない**
  （クローズドテストだけではストア検索に出ないため）。
- **したがって順番は「製品版公開 → ストア掲載 → AdMob リンク → アプリ承認 → 広告オン」。**
  広告を待って公開を止めるのは逆。

### 事前登録は**挟まない**方針（今回の判断）
事前登録は需要を「溜める」機能であって「作る」機能ではない。現状 TikTok は数十再生で、
箱を用意しても入らない。かつ期間中はアプリがダウンロードできず、AdMob も止まる。
→ **先に静かに製品版へ出し、その後で宣伝する**。

### 言語まわり（CEOの英語ファースト方針は正しく実装されている）
- `i18n.py` の既定は `en`。実機が日本語だったのは**その端末で切り替えたから**で、不具合ではない。
- ただし **`lang` は `save_code.py` の `SAVE_KEYS` に無く保存されない** = 開き直すと英語に戻る。
- リリースノート欄の `<ja-JP>` は**ロケール枠**であって中身の言語ではない
  （英語で書いた掲載情報が ja-JP 枠に入っていることは普通にある）。**掲載情報の言語一覧は未確認**。

### 環境メモ（03_開発部.md の記述と食い違う点）
- 「開発サンドボックスから GloBI は 403」と `03_開発部.md` にあるが、**このセッションでは
  ローカルから GloBI も xeno-canto も問題なく取得できた**。Cloud 経由は不要だった。
- Windows + OneDrive で `gradlew assembleDebug` が
  `Unable to delete directory ...packageDebug\tmp` で落ちることがある。
  → `./gradlew --stop` してから当該 tmp を消せば通る。
- **`gradlew` が BUILD FAILED でも `adb install` は成功しうる**（古い APK が残っているため）。
  ビルド結果を必ず確認してからインストールすること。
