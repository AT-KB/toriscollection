## 2. 進め方の背骨(ここだけは崩さない)

出典『2026-08-18 作業方針』。**この5つが一番よく効いた。**

1. **推測で書かない。一次情報を読む。** ID も文言も数値も、`data.py` /
   `i18n.py` / 実装と突き合わせてから使う。勘で書いて実際に外したことが何度もある。
2. **答えは Python から取る。** 手で期待値を書かない。`tools/logic_fixtures.py` が
   Python を回して JSON に落とし、Dart がそれと一致するかを見る。
3. **テストは「落ちること」を確かめてから信じる。** 新しいテストを足したら、
   わざとコードを壊して落ちるのを見る。**規則(監査)も同じ**
   — 2026-08-21 に緩すぎる正規表現と文字列一致の誤検出で2回やらかした。
4. **監査をすり抜けた不具合が出たら、不具合を直して終わりにしない。**
   同じ**種類**を次に捕まえる規則を足す。
5. **交渉不能の5原則**(受動的 / 罰しない / 声と癒しは無料 / 生態に誠実 /
   かわいさ優先)は**宣伝物にも効く**。映っていないものを宣伝で言わない。

## 3. 何度も人を止めた罠(全部実際に踏んだ)

### 🔴 LP を直しても本番に出ない
`torriscollection.com` は **`AT-KB/aviation-note-site`** の GitHub Pages。
`landing/` は原稿。公開は向こうへ `index.html` をコピーして push。
**`index.html` 以外は触らない**(CNAME と app-ads.txt が同居している)。
→ §7.5(2026-08-21)、2026-08-10

### 🔴 Play は「アップロードしただけ」では配信されない
アップロード後、**リリースを作って「公開を開始」まで押す**必要がある。
`公開の概要` に保留が出ていたら、そこで送信するまで永久に「未公開」。
versionCode **7 はこれで丸一日止まっていた**(状態が「非アクティブ」)。
→ 2026-08-21

### 🔴 release ビルドでしか出ない不具合がある
- **R8 が Room の生成クラスを消して起動即クラッシュ**(広告が WorkManager を
  連れてくる)。`proguard-rules.pro` で keep。**debug では再現しない。**
- **DEBUG の赤帯**はストア用スクショに写る。撮影は必ず release で。
→ 2026-08-21

### 🔴 「移してあるのに誰も呼んでいない」
台帳は**宣言があるか**しか見ない。中身が違っても「済み」と出る。
実際、**「移した」100件のうち35件が一度も突き合わせられていなかった**。
ラジオが会っていない鳥まで鳴らしていたのはこれ。
→ 対策は §6.5(未検証のラチェット / ゼロ状態テスト / 主張のテスト化)

### 🔴 台帳は Python の**公開関数**しか数えない
UI 関数の**中に直接書かれた条件**は載りようがない。外部リンクの移植漏れ
(2026-08-19)も、ラジオの絞り込み(2026-08-21)も、どちらもこれ。
**移植で条件を見つけたら、関数に切り出して突き合わせ対象にする。**

### 🔴 OneDrive 配下で release ビルドが落ちる
`build/.cxx` のロック。消せば通る。

### 🔴 動画の音が**途中から消える**(loudnorm → afade)
`loudnorm` は、測った LRA が目標を超えると `linear=true` を諦めて
**dynamic モードに落ち、そのとき出力を 96k/192kHz に変える**。
すると後段の `afade=t=out:st=14.6` が実時間の 1/2〜1/4 の位置に落ちて、
**動画の途中から先が丸ごと無音**になる。エラーは出ない。見た目も変わらない。
→ **loudnorm の直後に必ず `aresample=48000`**(`build_feature15._loudnorm`
に入れてある)。2026-08-25 に q02 が「3秒以降まるごと無音」で出た。
**書き出したら音を測る**(`volumedetect` を区間ごと / `ebur128`)。

### 🔴 鳴き声の録音は**頭に間があり、途中も休む**
そのまま流すと「冒頭2秒が無音」「15秒のうち10秒が無音」になる。
TikTok では致命的。→ `build_quiz15._segment` が**頭出しとひと節の長さを測り**、
ひと節を繰り返して鳴らす(鳥は実際にそうするので嘘にならない)。
旧 `build_quiz.py` に手打ちの「音の頭出し」があったのは、これが理由。

### 🔴 実機で**起動できるのは `.dev` だけ**(2026-08-25 時点)
`com.toriscollection.toris_app` は**起動できるアクティビティが無い**
(`cmd package resolve-activity` が No activity found)。
Play の `com.toriscollection.app` は**端末に入っていない**。
→ 画面の確認も撮影も `.dev`(別データなので CEO の庭・目覚ましに触れない)。

**`.dev` の DEBUG の赤帯は、上端を切れば消える。**
1080幅なら **150px**、720x1600 の録画なら **100px**(release 用の
`STATUS = 64` では足りない)。**これで `.dev` でも宣伝素材が撮れる。**
撮ったもの・撮り方・見つかった不具合は
`marketing/phase-1/SNS部/2026-08-25_実機素材_撮れたものと分かったこと.md`。

## 4. 実機を触るときの作法

出典『2026-08-18 作業方針』§6 + 実地で足したもの。
