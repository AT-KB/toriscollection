## 2. 言い切ったことと、その根拠

| 字幕の言い切り | 根拠(一次情報) |
|---|---|
| Plant what actually grows there. | 植えられるのは**その土地の植物だけ**(`data.PLANTS[x]['biome']`、`garden_page.dart` の `availablePlants`)。Charlotte は `max_plants = 4` |
| The insects come. Then the birds. | 植物 → 虫(`INSECTS[x]['eats_plants']`)→ 鳥(`BIRDS[x]['eats_insects']`)。**動画の中で `data.py` を読んで経路の実在を確かめてから描いている**(`_check_plant_chain`) |
| An American backyard / Or a Kyoto garden. | `data.BIOMES` は **Charlotte と Kyoto の2つ**。画面の見出しは "Your land"、名前は `name_en` |
| Different land, different birds. | 顔ぶれは `biome_pref` で決まる。出した6種は全部その土地の鳥だと実行して確認(`_check_lands`) |
| Real recordings. Nothing generated. | 鳴き声は xeno-canto の実録音、環境音は Freesound の CC0 |
| The ones you've met sing closest. | `radio_engine.dart` の `_obs_to_depth` — **観察回数が奥行きを決める**。手前ほど音量が大きく残響が浅い(`kDepthGain` / `kDepthWet`) |
| Meet it up close. | `guide_page.dart` — 近くで会うと図版が**アイコンから詳細画に入れ替わる** |
| The guide keeps the reason it came. | `eco_log.dart` に**削除関数が無い**(Python 版も append のみ)。庭が痩せても消えない(原則2) |

**画面に出した中身は、ぜんぶ `data.py` / `bird_profile.py` を実行して取った。**
Northern Cardinal のページに出ている Likes(Flowering Dogwood / Eastern Redbud /
Tulip Tree / Eastern Tent Caterpillar)・Home(Charlotte)・Fears(Snakes /
Crows and jays / Hawks)・学名・説明文は、**アプリが出すのと同じ値**。
「なぜ来たか」の一文も `i18n.py` の出荷済みの英語をそのまま使っている。

**見本の数字はここだけ**: バッジの「🌱 12 days together」。
会った日数は人によって違うので、**形式だけ実物に合わせた見本**(`_badge` と同じ書式)。

### 途中で止めた誤り(記録として)

- g01 の虫が **🐛 の絵に「Monarch Butterfly」の名前**になっていた
  (dogwood を食べる虫の先頭がチョウだった)。芋虫を優先して選ぶように直した。
- g02 で Cardinal / Blue Jay / Wren を出そうとしたが、**配布可プールに
  その3種の録音が無く**、画面の鳥と鳴っている録音が別になるところだった。
  録音のある3種(Downy / Pileated / Ruby-throated Hummingbird)に差し替えた。
- g06 の「終わる時刻」を `× Until 6:29 AM` と書いていた。
  **スリープは最長90分**なので朝までは有り得ない。`× Until 10:30 PM` に直した。
- g04 の ★ と 🌸🌳🐛 が**豆腐(□)**になっていた。★ は Segoe UI Symbol、
  絵文字は Segoe UI Emoji と、**フォントを分けて焼く**ように直した。

## 4. 実機の撮影について(CEO「実機いるなら言ってくれ」)

**いまの13本は実機なしで作れている。** 組み立てで作るのは CEO 2026-08-18 の
「必ずしも実機の撮影ではなくていい」に沿った方針で、画面録画には限界がある
(UIの雑音が映る / 鳥の到来は実時間でしか起きない / 字幕の帯に隠れる欄がある)。

**ただし、実機があると明確に強くなるのは次の3つ。** どれも「本物の画面が
動いている」ことが売りになるところで、組み立てでは出せない説得力がある。

| 欲しい素材 | どの動画に効くか | 撮り方(`tools/video_build/README_素材の撮り方.md` の型) |
|---|---|---|
| **目覚ましが実際に鳴っている画面** | `f01` / `g05` | Wake タブ → 数分後にセット → **実際に鳴らして録画**。静かに始まって声が増えるところが売り |
| **図鑑を開いて詳細が出る操作** | `f05` / `g04` | Guide タブ → 種を開く → 詳細画とWHY IT CAMEまでスクロール |
| **ラジオで環境音を重ねる操作** | `f03` / `g03` | Radio → Listen → 環境音タイルを3つ叩く。**指が触れて音が増える**のが見える |

撮る場合の注意(README より):
- **release ビルドで撮る**(debug は DEBUG の赤帯が映る)
- 上端64pxを落とす(`build_showcase.py` は自動、静止画は自分で切る)
- `screenrecord` は `--time-limit` ぶん待ってから `pull`(切ると 0KB になる)
- **CEO の設定(目覚ましの時刻・鳥・庭・土地)は変えない。** 検証は `.dev` で

撮ってもらえれば、`build_showcase.py` の型で実画面版を別に作れます。
**いま出せる13本は実機なしで完成しているので、出しながら並行で撮る形で構いません。**
