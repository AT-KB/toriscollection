# TikTok か X か — 事例を調べたうえでの考察(2026-08-21)

CEO「TikTokで再生数が100くらい、DLには一切つながっていない。TIKTOKかXか
どっちでプロモーションしていくべきか。初期なので多少課金してもいいと思うけど、
事例を調べたうえで考察して」。

**結論(先に)**
1. **100再生で0DLは、チャネル選択の材料にならない。** 算数の上で0が期待値。
2. それでも選ぶなら **TikTok**。X は cold start の発見性が無く、事例も見つからない。
3. **課金より先に、まだ読んでいない数字がある**(バッチ1の完全視聴率と視聴者の国)。
4. 課金するなら **量ではなく情報を買う**。伸びた1本を Spark Ads で押す。

---

## 1. まず、100再生で0DLは異常ではない

| 段 | 率(業界の一般値) | 100再生のとき |
|---|---|---|
| 再生 → プロフィール訪問 | 1〜3% | 1〜3人 |
| プロフィール → ストアへ | 2〜3割 | 0〜1人 |
| ストア → インストール | 2〜3割 | **0〜0.3人** |

**0 は期待値どおり。** ここから「TikTokは効かない」とは言えない。
言えるのは**リーチが実質ゼロ**ということだけで、これは 2026-08-08 の診断書が
すでに原因を特定している(冒頭3.2秒が静止画に見える / 15秒は完走されない /
日本地域のアカウントに英語テキスト / "link in bio" で配信が絞られる)。

**チャネルを変える前に、直した型が効いたかを見るのが先。**

## 2. ⚠️ 未読の数字がある(ここが最大の問題)

引継ぎ 2026-08-18 §7 の宿題:

> TikTok | **バッチ1の完全視聴率を CEO からもらう(比較の基準が無い)**

8秒型に作り直した効果を**まだ誰も測っていない**。再生数(100)だけでは、
「型が悪い」のか「配信が伸びていない」のか区別できない。

**見るべきは3つだけ**(TikTokアナリティクス):
- **完全視聴率** — 8秒型で上がったか。ここが上がらない限り何本出しても同じ
- **平均視聴時間 / 1秒残存** — 冒頭で切られているか
- **視聴者の国** — 日本が多いなら、英語テキストのままでは読まれない(診断書 1-3)

これを読まずに課金すると、**効かない creative に金を出す**ことになる。

## 3. TikTok か X か — 調べた結果

### この製品には**2つの需要**があり、両方 TikTok に居る

| 需要 | TikTok での実勢 |
|---|---|
| cozy game | `#cozygaming` **245.7K投稿**。競技系に比べ**供給が薄く**、参入が有利とされる |
| 野鳥 | `#birdwatching`/`#birding`/`#birdtok` 合計 **10億再生超**。RSPB は1年で約900万再生、**うち約1/3が24歳以下**。Gen Z の birding ブームが報じられている |

**この2つ目を、いまの動画は使っていない。** 現行の型は cozy 側だけを売っている。
本物の xeno-canto 録音と GloBI の食物網は **birder が反応する素材**で、
10億再生規模のタグに接続できる**未使用の入り口**。

### X は cold start に向かない

- App Install の広告目的自体はある。ただし**インディーの成功事例が見つからない**
  (検索で出るのは一般的な運用ガイドばかり)。
- birder は X を**珍鳥アラートの実用**に使っている。**cozy game の発見**の場ではない。
- 構造的に、**フォロワー0のアカウントを配る仕組みが無い**。TikTok の FYP は
  フォロワー0でも初期プールに配る — cold start では決定的な差。

→ **X を主戦場にする根拠は、調べた範囲では見つからなかった。**

## 4. 課金するなら(2026年の実勢)

| チャネル | Android カジュアルの CPI |
|---|---|
| TikTok(アプリインストール) | 中央値 **$1.09**(グローバル) / **$1.48**(米国)。CPM は最安水準 $3.50 |
| Android カジュアル全体の平均 | **$1.50** |
| Google Ads(App Campaigns) | **$1.5〜$4.5**(競争と最適化次第) |

数字上は TikTok が有利。ただし**この製品では、いま量を買うのは早い**:

- **広告がまだ配信されていない**(ユニットが新しく no-fill)。課金で入れた人は
  1円も生まない。**回収の当てが無い状態で CPI を払うのは、ただの支出。**
- **リテンションを測っていない。** 入れた人が翌日残るか分からないうちに量を買うと、
  「悪い人を大量に買った」だけで終わる。

**だから課金は「量」ではなく「情報」に使う。**

### 具体案: Spark Ads で**伸びた1本だけ**を押す

- 新規に広告用の動画を作らない。**オーガニックで最も完全視聴率が高かった1本**を
  Spark Ads で配信する(実績のある creative を増幅する形)。
- 予算は**1本あたり数千円**。目的は DL 数ではなく
  「**押せばリーチは伸びるのか / 伸びても DL に落ちないのか**」の切り分け。
  - リーチは伸びるが DL 0 → **ストアの掲載情報が悪い**(アイコン・スクショ・説明)
  - リーチも伸びない → **creative が悪い**
  この2つは、課金しないと切り分けられない。**これが買う価値のある情報。**

### Google App Campaigns は「あとで」

Play への導線としては素直だが、**掲載情報の出来に強く依存する**。
アイコンとスクショを入れ替えた直後なので、**まず数日オーガニックで様子を見てから**。

## 5. 推奨する順序

1. **アナリティクスを3つ読む**(完全視聴率 / 1秒残存 / 視聴者の国) — 費用0
2. 国が日本中心なら**日本語版の字幕を1本**出して比べる — 費用0
3. **BirdTok の入り口を1本試す**(実録音・なぜ来たか)。cozy とは別タグ — 費用0
4. ここまでで**伸びた1本**ができたら、それを **Spark Ads で数千円**押す
5. リテンションと広告フィルが見えてから、量(Google App Campaigns 等)を検討

**X は当面やらない。** やるとしても、リリース告知を置く場所として持つだけで、
獲得の主戦場にはしない。
