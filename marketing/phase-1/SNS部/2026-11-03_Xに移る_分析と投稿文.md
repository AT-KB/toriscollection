# X に移る — 分析と投稿文(2026-11-03)

CEO「TikTok で伸びないので、X にしようと思う。投稿文考えて、その前に分析しまくって」。

**結論(先に)**
1. **X に移る判断には、8月とは違う根拠がある。** 8/21 の調査は「英語・世界向け」が前提だった。
   いまは**日本語版がある**ので、**日本で X を使う人(6,700万〜7,000万人前後。米国に次ぐ2番目の市場)**が相手になる。
2. ただし**出す時期は 2.0.5 の公開後**。いま Play で配信中の 2.0.4 は**英語の画面**。
   日本語の投稿から英語のアプリに着くと、そこで離脱する。
3. **最大の弱点は「Android だけ」**。日本は iPhone の比率が高く、**見た人の多くが入れられない**。
   隠さず最初に書く(「入れられなかった」という不満がいちばん悪く広がる)。
4. X での個人開発の当たり方は**「1本のバズ → 1〜2日だけ大量に入る → 5日で元に戻る」**。
   狙って起こせないので、**打席数(投稿数)を設計する**。

---

## 1. TikTok の数字は、読めるものが無い

`analytics/posts.csv` の13本は、**再生数も完全視聴率も1行も入っていない**。
「TikTok で伸びない」を数字で確かめる材料はこちらに無い。

→ 判断を覆す材料にはしない。ただ、**TikTok に戻るかどうかを後で決めるため**に、
13本の「再生数 / 完全視聴率 / 視聴者の国」だけは一度写しておく価値がある(30秒×13本)。

## 2. 8月の「X はやらない」と、何が変わったか

| 8/21 の理由 | いま |
|---|---|
| X はフォロワー0を配る仕組みが無い | **おすすめ欄に載ればフォロワー数は関係ない**という個人開発の実例が出ている(下の「よりしろ」:フォロワーは写真界隈で、日記アプリとは無関係だったのに1日600DL) |
| birder は X を珍鳥情報の実用に使う | 変わらない。**だから野鳥の人だけを狙わない**(§4) |
| 英語ファースト | **日本語版ができた**(2.0.5)。日本は X の2番目の市場 |
| インディーの成功事例が無い | 日本語圏には**ある**(よりしろ・X広告1万円の検証) |

## 3. 日本の X で、個人開発アプリがどう当たるか(実例)

### よりしろ(日記アプリ・2026年6月)
- 告知ポスト **1本**(画像 + 平易な一文 + 「4ヶ月かけて作りました」 + 詳細はツリーに)
- 翌日 **600DL**。ストアのランキングが圏外 → 50位
- その後 **60 → 29 → 13 → 13 → 7**。**5日で元の水準**
- 600DL の**ほぼ全部が X から**。フォロワーからは数名
- 5日後のプレスリリース(PR TIMES + 90社)は **ほぼ無風**(1日5件・3件)
- 本人の学び: **「バズは狙えないが、打席数は設計できる」**

### X 広告に1万円(個人のアプリ・2025年1月)
- 新規 **約70DL** → **1DL あたり約143円**(こちらで割った値)
- 本人は「もっと期待していた」

→ **いまは広告を買わない。** AdMob が未承認で、入った人から1円も生まれない。
   承認されて「1人あたりいくら生むか」が見えてから比べる。

## 4. 誰に向けるか — 3つの層

| 層 | 刺さるもの | タグ(1投稿に1〜2個まで) |
|---|---|---|
| **癒し・寝落ちの人**(いちばん大きい) | 鳥の声 + 雨/焚き火/せせらぎ、鳥の声で起きる目覚まし | 付けない、または `#癒し` |
| **野鳥が好きな人** | 本物の録音、和名、京都の庭(メジロ・シジュウカラ)、食物網 | `#野鳥` `#バードウォッチング` |
| **個人開発の人** | 作る過程。「ぴょんぴょんが時計仕掛けに見えたので直した」 | `#個人開発` |

**個人開発の層は DL には弱いが、拡散(リポスト)に強い。** おすすめ欄に乗る最初の燃料になる。

## 5. X の仕組みで気をつけること(出典はどれも第三者のブログ。公式の数字ではない)

- **外部リンクは本文に入れない。リプ欄に置く。** 本文にリンクがあると届く範囲が下がる、
  という報告が多い(下がり幅は30〜90%以上とまちまち。X は否定しているという話もある)。
  どちらにしても、**リプ欄に置けば損はしない**。
- **画像・動画は X に直接上げる**(YouTube などのリンクにしない)。
- **返信がいちばん効く**。いいねより返信の重みが大きいという報告。
  → **質問で終わる投稿**(鳴き声クイズ)と、**もらった返信に必ず返す**。
- ハッシュタグは **2個まで**。
- 動画は**冒頭0.5〜1秒で動く**(TikTok で学んだことがそのまま使える)。

## 6. 測り方

**Play のリンクに目印を付ける**(どこから来たか Play Console で分かる):

```
https://play.google.com/store/apps/details?id=com.toriscollection.app&referrer=utm_source%3Dx%26utm_campaign%3D2026-11
```

Play Console → **ユーザー獲得 → 獲得レポート** で `x` からの訪問とインストールが見える。

**2週間・14投稿**で見るもの:
- 投稿ごとの**インプレッション / 返信 / プロフィール訪問**(X のアナリティクス)
- Play の **`utm_source=x` の訪問とインストール**
- **どの層の投稿が伸びたか**(§4 の3つ)。伸びた層に寄せる

## 7. 投稿文

⚠️ **2.0.5(日本語版)が Play で公開されてから出す。**
⚠️ 文字数は X の上限(日本語で約140字)に収めてある。
⚠️ 言い切っていることは、どれもアプリで確かめた事実(§8)。

### ① 固定ポスト(最初の1本。いちばん大事)

**添付**: 鳥が庭に来て、鳴いて、図鑑に入る**10秒前後の動画**(日本語の画面・音あり)

> 庭に植物を植えると、虫が来て、その虫を食べる鳥がやってくる。
> そんな小さな生態系を育てるアプリを、個人で作りました🐦
>
> 鳴き声は、世界中の録音者が残した本物の録音です。
> 会えた鳥だけが、あなたのラジオで歌います。
>
> Android版・無料(リンクはリプ欄に)

**そのリプ(自分で続ける)**:

> Google Play はこちらです👇
> (utm 付きリンク)
>
> ごめんなさい、iPhone版はまだありません。
> 「iPhoneでも欲しい」と思ってもらえたら、このポストにひとこと残してもらえるとうれしいです。

→ iPhone の人の返信が**そのまま返信の数になる**。需要の計測にもなる。

### ② 鳴き声クイズ(返信を集める型。週1〜2)

**添付**: その鳥の録音が流れる動画(絵は**シルエット**か「？？？」の図鑑)

> この声、だれでしょう?🐦
> 日本の庭でもよく聞く鳥です。
>
> 答えは明日、リプ欄で。
> #野鳥

→ 翌日、同じポストのリプ欄に答え(和名・ドット絵・**録音者のクレジット**)。

### ③ 寝落ち(いちばん大きい層)

**添付**: ラジオの画面で、焚き火 + 鳥の声が鳴っている動画

> 雨、焚き火、せせらぎ。そこにときどき、鳥の声。
> 15分〜90分で止まる「寝落ち」をつけてあります。
>
> 今夜はどの音で眠りますか?

### ④ 目覚まし

**添付**: 目覚ましの画面 + 鳴り始めの音

> アラームの電子音のかわりに、鳥のさえずりで起きる。
>
> 聞こえるか聞こえないかの小さな音から始まって、
> 少しずつ大きくなります。
> 庭で近くで会えた鳥たちが、朝のコーラスに加わります。

### ⑤ 京都の庭(野鳥の人向け)

**添付**: 京都の庭にメジロ・シジュウカラが来ている画面

> 京都の庭には、メジロやシジュウカラ。
> アメリカ・シャーロットの庭には、真っ赤なショウジョウコウカンチョウ。
>
> 植えた植物と、そこに来る虫で、来る鳥が変わります。
> #野鳥 #バードウォッチング

### ⑥ つながり(食物網)

**添付**: つながり画面のスクショ(和名が並んでいるもの)

> どの鳥が、どの虫を食べて、その虫はどの植物に来るのか。
> 実際の観察記録(GloBI)をもとに、つながりを描いています。
>
> 庭に植えるものを変えると、この網が変わります🌿

### ⑦ 開発ログ(個人開発の層。今日の直しがそのまま使える)

**添付**: 直す前(2〜3羽が一緒に動く)と直したあと(1羽ずつ)の並べた動画

> 「鳥たちが全部同じタイミングで動いてる気がする」と言われて調べたら、
> 1羽が枝を移るたびに、同じ枝の鳥まで横にずれていました。
>
> 直して、テンポも1羽ずつ変えました(2秒/2.75秒/3.25秒)。
> #個人開発

### ⑧ 日本語版リリース(2.0.5 公開の日に)

> 日本語に対応しました🇯🇵
>
> 鳥・虫・植物の名前も、ぜんぶ和名で出ます。
> (ルリツグミ、ズアカアメリカコゲラ、オオカバマダラ…)
> 右上のボタンで、いつでも英語と切り替えられます。

## 8. 言い切りの確認(`06_監査.md` §3 の主張台帳)

| 言い切り | 確かめた場所 |
|---|---|
| 植物 → 虫 → 鳥 | `toris_core` の食物網(`FoodWeb`)、つながり画面 |
| 鳴き声は本物の録音 | `assets/birds/_credits.json`(xeno-canto、録音者つき) |
| 会えた鳥だけがラジオで歌う | `radio_page.dart`(observed のみ。8/21 に直した主張) |
| 寝落ち 15〜90分 | ラジオの「寝落ち」15/30/60/90分 |
| 小さな音から少しずつ大きく | 目覚ましの説明文と `BirdAlarmService` |
| 近くで会えた鳥がコーラスに加わる | `alarm_page.dart`(2羽目・3羽目は会えた鳥から) |
| 実際の観察記録(GloBI) | `predators.json` / 食物網のデータ出典 |
| 和名・切替ボタン | 2.0.5(2026-11-03 実装・実機確認) |

**新しく言い切っているのは「和名」と「切替ボタン」だけ**。2.0.5 公開前に出すと嘘になる。

## 9. やらないこと

- 広告を押してほしい、と書かない(AdMob の規約違反)
- 「◯万人が遊んでいる」など、数字を盛らない
- 野鳥アカウントへの宣伝リプ。**宣伝ではなく、相手の投稿への本当の感想だけ**
- ハッシュタグを3個以上付けない
